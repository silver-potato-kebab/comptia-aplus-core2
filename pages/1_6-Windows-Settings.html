OVERVIEWTwo Interfaces, One System

Windows configuration lives in two places — the classic Control Panel and the modern Settings app — and understanding both is mandatory for the A+ exam. Control Panel dates to Windows 1.0 and remains the authoritative home for many system-critical tools. The Settings app (introduced in Windows 8 and expanded in Windows 10/11) provides a touch-friendly, redesigned interface that has absorbed many Control Panel functions while leaving others behind. Microsoft is slowly migrating all settings to the Settings app, but as of Windows 11, both interfaces remain essential.

This objective tests your ability to navigate to specific settings, understand what each setting does, and apply the correct configuration in a given scenario. The exam frequently presents a description of a problem or task and asks which setting panel or specific option to use. The path to the setting is often as important as the setting itself.

How to Open Each Interface

Control Panel: Search "Control Panel" in Start, or run control from the Run dialog (Win+R). Can be opened directly to specific applets with run commands: control inetcpl.cpl (Internet Options), control printers (Devices and Printers), control userpasswords2 (User Accounts), etc. Settings App: Win+I is the universal keyboard shortcut. Right-clicking the Start button reveals a quick-access menu for Device Manager, System, Network Connections, and more — faster than navigating through Control Panel.

Control Panel Items (Legacy)

  • Internet Options — IE/legacy browser + network proxy settings
  • Devices and Printers — add/manage printers and devices
  • Programs and Features — uninstall/modify software
  • Network and Sharing Center — network status and configuration
  • System — computer name, hardware info, performance
  • Windows Defender Firewall — inbound/outbound rule management
  • Mail — Outlook mail profile configuration
  • Sound — playback, recording, and sound scheme management
  • User Accounts — local account management and UAC
  • Device Manager — hardware driver status and management
  • Indexing Options — Windows Search index configuration
  • Administrative Tools — advanced system management utilities
  • File Explorer Options — folder view and hidden file settings
  • Power Options — power plans and sleep/hibernate settings

Settings App Sections (Modern)

  • System — display, notifications, power, storage
  • Devices — Bluetooth, printers, mouse, keyboard, pen
  • Network & Internet — Wi-Fi, VPN, proxy, Ethernet status
  • Personalization — background, colors, lock screen, themes
  • Apps — app management, default apps, optional features
  • Accounts — sign-in options, Microsoft account, work/school
  • Time & Language — date/time, region, language, speech
  • Gaming — Game Bar, Game Mode, Xbox integration
  • Ease of Access — accessibility features for vision, hearing, mobility
  • Privacy — app permissions, diagnostics, location, camera, mic
  • Update & Security — Windows Update, Windows Defender, backup, recovery

SECTION 1Control Panel Settings

The Control Panel remains the primary location for many system-critical configuration tasks. Its applets provide deeper access to system internals than the Settings app. Each applet is also directly accessible via Run dialog commands, making them accessible even when the Start menu is unavailable.

Internet Options

Control Panel → Network and Internet → Internet Options  |  Run: inetcpl.cpl

Internet Options configures settings for Internet Explorer and the legacy Edge engine, but also controls system-wide proxy settings, certificate management, and security zones that affect all Windows applications using the WinINet API (including many enterprise applications, Windows Update, and Outlook). Even on systems where Chrome or Firefox is the primary browser, Internet Options remains relevant for proxy and security zone configuration.

Internet Options — Tabs Reference inetcpl.cpl
General Tab
Sets the browser home page, startup behavior (start with tabs from last session), browsing history (delete cookies, cached files, saved passwords, history, form data), and tab behavior. Home page changes here affect IE and some legacy embedded browser applications.
Security Tab
Configures security zones — Internet, Local intranet, Trusted sites, and Restricted sites. Each zone has a security level (High/Medium/Low/Custom) that controls ActiveX, scripting, file downloads, and authentication behaviors. Enterprise environments add intranet servers to the Local intranet zone to allow single sign-on without authentication prompts.
Privacy Tab
Controls cookie behavior per security zone and enables the pop-up blocker. Pop-up blocker settings allow exceptions for trusted sites — enterprise web apps often require pop-up exceptions to function. Also controls InPrivate browsing settings.
Content Tab
Manages SSL/TLS certificates (view, import, export, delete personal certificates, trusted root CAs, intermediate CAs). Also manages AutoComplete settings (saved form data, usernames, passwords) and RSS feed subscriptions. Certificate management here affects all Windows applications, not just IE.
Connections Tab
Proxy server configuration — the most important tab for technicians in enterprise environments. "LAN Settings" button opens the proxy configuration: enable/disable proxy, set proxy server address and port, and configure bypass list. These proxy settings apply to all applications using WinINet (IE, Windows Update, many enterprise apps). Also manages VPN and dial-up connection settings.
Programs Tab
Sets default programs for email, newsgroups, internet calls, calendar, and contacts that launch from within the browser. Also manages HTML editor associations and add-on management (browser extensions and toolbars for IE).
Advanced Tab
Fine-grained settings for security (which TLS versions to use — TLS 1.0, 1.1, 1.2, 1.3), browsing behavior, multimedia, and accessibility. TLS version settings here are critical — some older enterprise applications may require enabling older TLS versions. The "Reset" button restores all Internet Options to defaults, useful when browser settings are suspected to be misconfigured or malware-altered.

Exam Focus — Internet Options

The Connections tab → LAN Settings is where proxy server address and port are configured for the entire system. A scenario where "a user can access websites but enterprise applications can't reach internal servers" → check proxy settings / intranet zone in Internet Options. A scenario about managing trusted root certificates → Content tab → Certificates. Pop-up blocker exceptions for a required enterprise web app → Privacy tab.

Devices and Printers

Control Panel → Hardware and Sound → Devices and Printers  |  Run: control printers

Devices and Printers is the Control Panel hub for viewing and managing all connected printers, scanners, Bluetooth devices, and other peripherals. It provides a visual representation of connected devices and allows right-click context-menu access to device-specific management options.

Add a Printer The "Add a printer" wizard searches for available printers automatically (network printers via WSD or Bonjour broadcast, Bluetooth printers) and allows manual entry of a printer address (IP or hostname). For TCP/IP network printers, select "The printer that I want isn't listed" → "Add a printer using a TCP/IP address or hostname" → enter the printer's static IP. This creates a Standard TCP/IP Port monitor pointing to the printer.
Set as Default Printer Right-click any printer → "Set as default printer." Windows marks the default printer with a green checkmark. The default printer is what applications use when the user prints without explicitly choosing a printer. Windows 10/11 has a "Let Windows manage my default printer" feature that automatically sets the most recently used printer as default — this can confuse users who expect a fixed default and should often be disabled in enterprise environments.
Printer Properties vs. Printing Preferences Printer Properties (right-click → Printer properties): manages the printer's hardware configuration — ports, sharing settings, security permissions, driver version, and spooler settings. Printing Preferences (right-click → Printing preferences): manages default print settings — paper orientation, paper size, color vs. grayscale, duplex (two-sided), print quality. Properties = device admin; Preferences = print job defaults.
View Print Queue Double-clicking a printer opens the print queue — a list of pending and in-progress print jobs with their status. From the queue, a technician can pause individual jobs, cancel jobs, or cancel all documents. Stuck print jobs (jobs that won't cancel through the normal UI) require stopping the Print Spooler service (services.msc → Print Spooler → Stop), manually deleting files from C:\Windows\System32\spool\PRINTERS\, then restarting the spooler service.
Print Spooler Service The Print Spooler (spoolsv.exe) is the Windows service that manages the print queue, accepts print jobs from applications, stores them temporarily on disk, and sends them to the printer in order. A crashed or hung spooler affects all printing. Restart it via Services console or: net stop spooler → clear spool files → net start spooler.

Programs and Features

Control Panel → Programs → Programs and Features  |  Run: appwiz.cpl

Programs and Features lists all installed software with version, publisher, install date, and size. It is the primary Control Panel location for uninstalling, modifying, or repairing installed applications and for managing Windows Features.

Programs and Features — Key Functions appwiz.cpl
Uninstall a Program
Select an application → click Uninstall. Runs the application's own uninstaller. If an application doesn't appear here (malware, improperly installed software), use the vendor's standalone removal tool or a third-party uninstaller. Note: simply deleting program folders does not uninstall software — it leaves registry entries, start menu items, and services behind.
Change / Repair
Some applications (Microsoft Office, Visual Studio) show "Change" or "Repair" options alongside Uninstall. Change opens the application's installer to add or remove components. Repair re-runs the installer to fix corrupted or missing files without removing user data or settings. Use Repair when an application is malfunctioning but uninstall/reinstall is too disruptive.
View Installed Updates
Left panel link "View installed updates" lists all Windows updates installed on the system, with their KB article number, install date, and the option to uninstall individual updates. Useful for rolling back a problematic Windows Update that broke functionality after installation.
Turn Windows Features On/Off
Opens the Windows Features dialog listing optional OS components: Internet Explorer, Hyper-V, Windows Subsystem for Linux, .NET Framework versions, Telnet Client, TFTP Client, Remote Desktop Services, Windows Sandbox, and more. Features that are unchecked are not installed; checking them installs them from the Windows component store without installation media (internet connection may be needed for some).

Windows Features vs. Programs

"Turn Windows features on or off" manages optional Windows OS components — things that are part of Windows itself but not installed by default. Common exam scenarios: a technician needs to install Hyper-V to run virtual machines (Windows feature, not a separate download); enable Telnet Client for legacy network testing; enable Windows Subsystem for Linux (WSL) for Linux command-line tools on Windows. These are always found here, not in the Apps section of Settings.

Network and Sharing Center

Control Panel → Network and Internet → Network and Sharing Center  |  Run: control.exe /name Microsoft.NetworkAndSharingCenter

The Network and Sharing Center provides a unified view of the computer's network connections, their status, and access to all network configuration tasks. It shows the current network map, active connections, and links to key network management tasks.

Network Map / Status Displays the current network connection: the computer, the network (private or public), and the internet connection. Shows whether internet access is available. The label "No internet access" or "Limited connectivity" indicates the connection exists but internet routing or DHCP has failed. Clicking the network name opens its status dialog showing speed, signal, bytes sent/received, and a Properties/Diagnose button.
Change Adapter Settings Opens the Network Connections view listing all network adapters (physical and virtual). Right-click an adapter → Properties opens the adapter's protocol bindings — this is where IP address, subnet mask, default gateway, and DNS servers are manually configured (or DHCP is enabled) via IPv4 Properties and IPv6 Properties. This is the most common destination for manual IP configuration in a troubleshooting scenario.
Change Advanced Sharing Settings Controls network discovery (whether the computer is visible to other devices on the network), file and printer sharing, public folder sharing, and password-protected sharing. Separate settings exist for Private (home/work) and Public network profiles. Enabling file and printer sharing on the Public profile is a security risk — sharing should only be enabled on Private profiles.
Set Up a New Connection Wizard for creating new network connections: broadband (PPPoE), VPN connections, dial-up, and wireless ad-hoc networks. VPN connections created here appear in the network adapter list and can be initiated from the taskbar network menu. Enterprise VPN clients (Cisco AnyConnect, GlobalProtect) bypass this wizard with their own installers.
Network Profile (Public/Private) Each network connection is assigned a profile: Private (home/work — trusted network; file sharing allowed; network discovery on) or Public (untrusted — maximum firewall restrictions; network discovery off; sharing disabled). Changing the profile affects Windows Firewall rules and sharing behavior. A freshly connected network defaults to Public unless the user chooses Private during initial connection.
Homegroup (Legacy) Homegroup was a simplified home network sharing feature removed in Windows 10 version 1803. Replaced by standard workgroup sharing. If troubleshooting an older machine, Homegroup may still appear here — it is no longer supported and should not be configured on modern systems.

System

Control Panel → System and Security → System  |  Run: sysdm.cpl (for System Properties)  |  Win+Pause/Break

The System Control Panel applet provides essential hardware information and access to core system configuration settings. It displays the Windows edition, CPU, installed RAM, and system type (32-bit or 64-bit OS, 64-bit capable processor). This is the first stop when diagnosing hardware specifications or configuring computer identity settings.

System — Key Settings sysdm.cpl
Computer Name / Domain / Workgroup
The System Properties dialog (click "Change settings" or run sysdm.cpl) → Computer Name tab allows renaming the computer and joining or leaving a domain or workgroup. Domain join requires domain admin credentials and a reboot. The computer name must be unique on the network. Computer name changes require a reboot to take effect.
System Protection / System Restore
System Protection tab in System Properties enables/disables System Restore for each drive. When enabled, Windows automatically creates restore points before major system changes (updates, driver installs, application installs). Restore points capture registry state and protected system files — not personal files. Creating a manual restore point before risky changes is best practice. Restoring to a point reverts the registry and system files to that point's state.
Advanced — Performance Settings
Advanced tab → Performance Settings → Visual Effects: controls Windows animation and visual effects. On older or lower-spec hardware, disabling unnecessary animations ("Adjust for best performance") can noticeably improve responsiveness. Options include: animate windows, fade menus, smooth scroll, thumbnail previews — each can be individually toggled.
Advanced — Virtual Memory
Advanced tab → Performance → Advanced → Virtual Memory: manages the pagefile.sys (swap file). Windows uses pagefile as virtual RAM when physical RAM is exhausted. Allowing Windows to manage paging file size automatically is recommended for most systems. Manual configuration is appropriate for performance-critical servers. Placing the pagefile on a separate drive from the OS can improve performance. Setting pagefile to zero disables virtual memory — risky, not recommended.
Remote Settings
Remote tab manages Remote Desktop and Remote Assistance. "Allow remote connections to this computer" must be enabled for RDP connections to be accepted. Unticking "Allow connections only from computers running Remote Desktop with Network Level Authentication (NLA)" is sometimes needed for older RDP clients — but NLA should remain enabled for security in modern environments. RDP also requires the Windows Firewall to allow TCP 3389.

Windows Defender Firewall

Control Panel → System and Security → Windows Defender Firewall  |  Run: firewall.cpl

Windows Defender Firewall (formerly Windows Firewall) is the built-in host-based firewall that controls network traffic to and from the computer based on configurable rules. It operates independently of any network perimeter firewall and provides essential protection especially on laptops that connect to untrusted public networks.

Firewall On/Off per Profile Windows Firewall maintains separate rule sets for three network profiles: Domain (computer on a domain network), Private (trusted home/work network), and Public (untrusted public network). Each profile can have the firewall independently enabled or disabled. The Public profile should always have the firewall on at maximum protection. The Domain profile is typically managed by Group Policy in enterprise environments.
Allow an App Through "Allow an app or feature through Windows Defender Firewall" opens the application exception list. Checking an application here creates an allow rule for it in all or specific profiles. This is the simple interface — for granular control (specific ports, protocols, IP ranges), use Windows Defender Firewall with Advanced Security (wf.msc), which exposes the full inbound/outbound rule set.
Advanced Security (wf.msc) The advanced console exposes complete inbound and outbound rules, connection security rules, and monitoring. From here a technician can: create rules for specific ports (allow TCP 3389 for RDP), block specific applications, create rules that only apply on certain network profiles, and view which rules are currently active. Most firewall troubleshooting in enterprise environments uses wf.msc rather than the basic Control Panel interface.
Restore Defaults "Restore defaults" removes all custom rules and resets Windows Firewall to factory state. This is a valuable troubleshooting step when suspected misconfigured or malware-added firewall rules are blocking legitimate traffic or allowing malicious connections. Use with caution — any legitimate application exceptions added by IT will also be removed.

Exam Focus — Windows Defender Firewall

A scenario where "a newly installed application cannot communicate over the network" → Windows Firewall blocked it; add an exception in "Allow an app through Windows Defender Firewall." A scenario requiring granular port-level rules → wf.msc Advanced Security. RDP won't connect to a machine → check that Remote Desktop is allowed through the firewall (TCP 3389) and that Remote Desktop is enabled in System Properties → Remote tab. Never disable the firewall on the Public profile — this is explicitly a security mistake the exam expects you to recognize.

Mail

Control Panel → Mail (Microsoft Outlook)

The Mail Control Panel applet manages Microsoft Outlook mail profiles. It is only present on systems where Microsoft Outlook (from Microsoft 365 or Office) is installed. It is used to create, modify, and delete Outlook profiles, and to manage the data files (PST/OST) associated with each profile. This applet does not configure Windows Mail or any other email client.

Mail Profiles An Outlook mail profile is a named configuration that contains email account settings, data file locations, and address book references. A single user can have multiple profiles (e.g., "Work" and "Personal") and select which to open when Outlook starts. Profiles are stored in the registry and are user-specific. Corrupted profiles are a common cause of Outlook failing to start — creating a new profile and reconfiguring the account resolves this without losing email data (which is in the PST/OST file, not the profile itself).
Email Accounts Within a profile, one or more email accounts are configured — Exchange, Microsoft 365, IMAP, or POP3 accounts. The Mail applet allows adding, removing, or modifying account settings including server addresses, authentication, and sync settings. For Microsoft 365/Exchange accounts, the "Autodiscover" service typically configures settings automatically when just the email address and password are provided.
Data Files (PST/OST) PST (Personal Storage Table) — a local data file for POP3 accounts and Personal Folders; all email, contacts, and calendar items are stored locally. Can be backed up and moved between machines. OST (Offline Storage Table) — a local cache of an Exchange or IMAP account; the authoritative copy remains on the server. OST files cannot be directly imported to another machine — only PST files are portable. The Mail applet's "Data Files" tab shows the location of each data file.

Sound

Control Panel → Hardware and Sound → Sound  |  Run: mmsys.cpl

The Sound applet manages audio playback devices, recording devices, sound schemes (the audio cues for system events), and audio communications settings. It provides access to per-device volume levels, format settings, and exclusive mode controls that are not accessible through the taskbar volume icon.

Sound — Tabs Reference mmsys.cpl
Playback Tab
Lists all audio output devices (speakers, headphones, HDMI audio). The default device (green checkmark) receives system audio by default. The default communication device (different from default playback) handles communication apps like Teams and Zoom. Right-click → Set as Default Device / Set as Default Communication Device to change. Right-click → Properties → Advanced for sample rate, bit depth, and exclusive mode settings.
Recording Tab
Lists all audio input devices (microphones, line-in). Same default device concept as Playback. If a microphone isn't working, check here first — the device may be present but disabled (right-click → Enable) or the level may be set to zero. The "Levels" sub-tab in device Properties adjusts microphone gain and boost separately from the main system volume.
Sounds Tab
Maps Windows system events (startup, error, logon, notification, etc.) to audio files — the sound scheme. Schemes can be set to "No Sounds" to disable all system audio cues, or to one of Windows' built-in schemes. Custom sound schemes can be saved. This is the setting to change when a user complains about specific notification sounds or wants to mute system event sounds without muting application audio.
Communications Tab
Controls Windows' automatic communications ducking — when Windows detects a phone call or real-time communication, it can automatically reduce other sounds to 80%, mute them, or do nothing. Users who find their music muted during Teams calls should check this setting — "Do nothing" disables the ducking behavior.

User Accounts

Control Panel → User Accounts  |  Run: netplwiz (advanced)  |  control userpasswords2

The User Accounts Control Panel applet manages local Windows user accounts — creating, deleting, changing passwords, changing account types, and configuring User Account Control (UAC) behavior. It is distinct from the Accounts section in the Settings app, which focuses on Microsoft account sign-in and work/school account integration.

Account Types Administrator accounts have full system access — they can install software, modify system settings, create/delete accounts, and change security policies. Standard User accounts can use the computer and change their own settings but cannot make system-level changes without providing administrator credentials (UAC prompt). Best practice: users should operate with standard accounts and only elevate when necessary. Never give users administrator accounts for day-to-day use.
User Account Control (UAC) UAC is the security feature that prompts for confirmation or credentials when a program attempts to make system-level changes. The UAC prompt appears as a blue/grey dimmed desktop overlay. The UAC slider (User Accounts → Change User Account Control settings) has four levels: Always notify (highest) → Notify when apps try to make changes (default) → Notify without dimming the desktop → Never notify (essentially disabled). Lowering UAC increases convenience but reduces security — the exam expects you to know it should generally remain at the default or higher.
netplwiz (Advanced Accounts) Running netplwiz opens the "User Accounts" advanced dialog. This interface shows all local accounts, allows adding/removing accounts, and — critically — allows disabling the password requirement at startup: uncheck "Users must enter a user name and password to use this computer." This enables automatic login. Only appropriate for kiosk or single-user systems in physically secured locations. Never enable automatic login on a laptop or shared system.
Credential Manager Accessible from User Accounts, Credential Manager stores saved usernames and passwords for network resources, websites (in Windows Credential Store), and Windows applications. Saved credentials auto-fill authentication prompts for network shares and mapped drives. Outdated credentials (e.g., after a password change on a network share) cause authentication failures — deleting the old credential from Credential Manager forces a fresh authentication prompt.

Device Manager

Control Panel → System → Device Manager  |  Run: devmgmt.msc  |  Right-click Start → Device Manager

Device Manager is the single most important tool for hardware management in Windows. It lists every hardware device the OS knows about, displays the driver status for each, and provides controls to update, roll back, disable, and uninstall device drivers. It is the first stop for any hardware problem — unknown devices, driver conflicts, and disabled devices all surface here.

Device Manager — Icons and Status Indicators devmgmt.msc
⚠️ Yellow Exclamation
A device has a problem — driver is missing, corrupted, or incompatible. The device may be partially functional or non-functional. Right-click → Update driver, or Uninstall device → reboot to reinstall. Check the device's Properties → Details tab → Hardware Ids to identify the exact device and find the correct driver.
❌ Red X
A device is disabled. The hardware is present and has a driver but has been manually disabled in Device Manager or Group Policy. Right-click → Enable device to re-enable. Disabled devices consume no system resources.
⬇️ Down Arrow
Device is disabled (same as red X in newer Windows versions — a down-arrow overlaid on the device icon indicates a manually disabled device).
❓ Unknown Device
Hardware detected but no driver is installed and Windows cannot identify the device automatically. Common after installing new hardware. Look up the Hardware ID in the device's Properties to identify it, then download the correct driver from the manufacturer's website.
Update Driver
Two options: "Search automatically" — Windows checks Windows Update for a matching driver; "Browse my computer" — specify a local path to driver files (INF file and supporting files). For enterprise environments, always use Browse to supply the tested, approved driver rather than whatever Windows Update provides.
Roll Back Driver
Reverts to the previously installed driver version. Available only if a driver was recently updated — Windows keeps one prior version. Critical when a driver update breaks device functionality. If the device no longer works after an update, roll back immediately before troubleshooting further.
Show Hidden Devices
View menu → "Show hidden devices" reveals non-present devices (hardware that was connected and had a driver installed but is currently disconnected) and legacy non-Plug-and-Play drivers. Useful for cleaning up phantom devices that persist in Device Manager after hardware is removed.

Exam Focus — Device Manager

Yellow exclamation = driver problem (update/reinstall driver). Red X or down arrow = disabled device (enable it). Unknown device = no driver installed (get driver from manufacturer using Hardware ID). Roll Back Driver = device worked before a driver update, now doesn't — roll back is the first step. View → Show Hidden Devices = see phantom/disconnected devices. Device Manager is also where you can check if hardware is using DMA, IRQs, or I/O ports via Properties → Resources tab (advanced hardware conflict troubleshooting).

Indexing Options

Control Panel → Indexing Options  |  Run: control srchadmin.dll

Indexing Options configures the Windows Search indexing service — the background process that catalogs file contents and metadata so that searches in File Explorer and the Start menu return results instantly rather than requiring a live file system scan.

  • Indexed locations: By default, Windows indexes the user's home folder (Documents, Pictures, Music, Videos, Desktop) and Start menu. The index does not cover all drives by default — adding locations (e.g., a data drive or shared folder) improves search speed for those locations at the cost of disk space and indexing CPU time
  • Rebuild index: If search results are incorrect, missing, or returning stale data, rebuilding the index recreates the catalog from scratch. This can take several hours on systems with large file collections. Index is stored at C:\ProgramData\Microsoft\Search\
  • Advanced → File Types: Controls which file extensions are indexed and whether file contents (not just names/metadata) are indexed. Indexing file contents enables full-text search but increases index size and build time significantly
  • Troubleshooting slow search: A system that hangs or becomes slow when searching may have a corrupted or extremely large index. Pause indexing (via Services: Windows Search), clear the index location, restart the service, and allow rebuilding overnight
  • Exam scenario: A user complains that searching for files on their computer takes a very long time → check Indexing Options; the drive/folder may not be in the indexed locations list, or the index may need rebuilding

Administrative Tools

Control Panel → Administrative Tools  |  Run: control admintools

Administrative Tools is a folder of shortcuts to advanced Windows management consoles. These tools are used for in-depth system administration and go significantly beyond what the basic Control Panel or Settings app offer. Many A+ troubleshooting scenarios use these tools.

File Explorer Options

Control Panel → File Explorer Options  |  File Explorer → View → Options  |  Run: control folders

File Explorer Options (formerly Folder Options) controls how files and folders are displayed in File Explorer. Several of these settings are critical for technicians — hidden system files are invisible by default and must be revealed to troubleshoot many issues, and file extensions are hidden by default which can conceal malicious files disguised as documents.

File Explorer Options — Critical Settings control folders
View Hidden Files and Folders
View tab → "Show hidden files, folders, and drives." By default, files and folders with the Hidden attribute set are invisible in File Explorer. Changing this to "Show hidden files, folders, and drives" makes them visible. Hidden files appear slightly translucent (grayed out) to indicate their hidden status. Malware frequently hides in hidden folders like AppData — this setting is required to navigate there manually.
Hide Extensions for Known File Types
By default, Windows hides file extensions for registered file types — document.docx appears as just "document." This hides critical information and enables a social engineering attack: a malicious executable named invoice.pdf.exe displays as "invoice.pdf" with a PDF icon, tricking users into running it. Uncheck "Hide extensions for known file types" to always show extensions. Technicians should always enable this setting — it is a security best practice.
Hide Protected Operating System Files
View tab → "Hide protected operating system files (Recommended)." System files with both Hidden and System attributes (like pagefile.sys, hiberfil.sys, NTLDR, bootmgr) are hidden even when "Show hidden files" is enabled unless this option is also unchecked. Unchecking reveals these files. Accidentally deleting protected OS files is a risk — Windows prompts a strong warning when disabling this option.
General Tab — Open File Explorer to
Sets whether File Explorer opens to Quick Access (recent files and pinned folders — default) or This PC (shows drives and libraries). Power users and technicians typically prefer "This PC" for faster access to drives. Change to preference.
General Tab — Browsing Single/Double Click
Controls whether items open with a single click (web-style — hovering selects, single click opens) or double click (classic Windows style). Almost universally set to double-click; single-click can confuse users transitioning from web browsers.
View Tab — Apply to All Folders
"Apply to Folders" button propagates the current folder's view settings (icon size, sort order, grouping) to all folders of the same type. Useful for standardizing the view across all Documents folders or all Pictures folders. "Reset Folders" returns all folder views to Windows default settings.
Search Tab
Controls search behavior: whether to search file contents (slower but more thorough), whether to include compressed files (ZIP) in search results, and how to handle searches in non-indexed locations. "Always search file names and contents" provides the most complete search results but is significantly slower in non-indexed locations.

Security Implication — Hidden Extensions

The default Windows behavior of hiding known file extensions is a major social engineering enabler. An attacker sends a file named Important_Document.pdf.exe — with extensions hidden, the user sees Important_Document.pdf with whatever icon the attacker chose. Double-clicking it executes the malware. Always show file extensions on any computer you manage. This is one of the first settings a technician should change on a new system setup. The exam expects you to know that hiding extensions creates a security risk.

SECTION 2Power Options

Control Panel → Hardware and Sound → Power Options  |  Run: powercfg.cpl  |  Settings → System → Power & Sleep

Power Options controls how Windows manages power consumption — balancing performance against battery life and energy efficiency. These settings are especially important for laptops but also relevant for desktops in environments where energy consumption is a concern. Power management directly affects system availability, data safety, and hardware longevity.

Power Plans

A power plan is a named collection of hardware and system settings that defines how Windows balances performance and power consumption. Three built-in plans exist, and custom plans can be created. The active power plan governs display timeout, sleep timeout, processor performance state, and disk spin-down behavior.

Balanced (Default) The standard plan for most systems. Dynamically adjusts CPU performance based on demand — reduces CPU frequency when idle, increases it under load. Display turns off after 10 minutes, sleep after 30 minutes by default. Balances performance for active tasks with energy savings during idle periods. Recommended for laptops on battery and for general desktop use.
High Performance Keeps the CPU running at maximum frequency at all times. Display timeout and sleep timeout are set to longer durations (or never). Used for gaming, video editing, CAD workstations, and any application that benefits from consistent maximum CPU performance. Consumes significantly more power — not recommended for laptops on battery. On desktops, the power difference is usually worthwhile for performance-critical tasks.
Power Saver Reduces CPU frequency to minimum levels even under moderate load. Aggressive display and sleep timeouts. Screen brightness reduced. Used on laptops when battery conservation is the priority — extends battery runtime at the cost of noticeably reduced performance. May cause applications to feel sluggish.
Ultimate Performance (Enterprise) Available on Windows 10/11 Pro Workstation and Server editions. Even more aggressive than High Performance — eliminates any micro-latency from power management transitions. Targeted at high-end workstations where every cycle counts. Must be enabled via powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61 command if not visible.
Custom Plan Settings Any plan can be customized via "Change plan settings" → "Change advanced power settings." Advanced settings expose per-plan configuration for: processor minimum/maximum performance states, hard disk spin-down timeout, USB selective suspend, wireless adapter power saving mode, PCI Express link state power management, and sleep state settings. These granular settings matter for server environments and specialized hardware configurations.

Hibernate

Hibernate must be explicitly enabled on Windows 10/11 — it is sometimes disabled by default, especially when Fast Startup is enabled. Hibernate requires free disk space equal to the installed RAM (the hiberfil.sys file). On systems with 32 GB RAM, hibernate reserves 32 GB of disk space.

  • Enable hibernate: powercfg /hibernate on in an elevated command prompt; or Power Options → Choose what the power buttons do → "Turn on fast startup (recommended)" → click "Change settings that are currently unavailable" → check Hibernate
  • Disable hibernate (recover disk space): powercfg /hibernate off — removes hiberfil.sys and reclaims disk space. Appropriate on SSD-equipped desktops where disk space is valuable and hibernate isn't needed
  • Hybrid Sleep: Combines sleep and hibernate — saves RAM to both memory and disk simultaneously. On resume, wakes from memory (fast) if power was maintained; recovers from disk if power was lost. Enabled by default on desktops, often disabled on laptops where hibernate alone is preferred
  • hiberfil.sys size: Typically 75% of physical RAM (reduced size hibernate) or 100% (full hibernate). Reduced size is sufficient for most uses and saves disk space

Choose What Closing the Lid Does

Laptop-specific setting that defines the action taken when the laptop lid is closed, and optionally when the power button is pressed. Located in Power Options → "Choose what closing the lid does" (left panel). Each action can be set differently for On battery and Plugged in.

Lid Close / Power Button Actions

  • Do nothing — computer stays fully running when lid is closed; used for clamshell desktop mode with external monitor
  • Sleep — saves to RAM, low power; default for most laptops
  • Hibernate — saves to disk, powers off; best for extended transport
  • Shut down — full shutdown when lid closes; rare but sometimes used in kiosk deployments

Common Scenarios

  • Laptop used as desktop (closed lid): Set lid close → "Do nothing" so closing the lid doesn't suspend the session; external monitor, keyboard, and mouse continue working
  • User's laptop resumes when opened: Default behavior; lid open resumes from sleep automatically
  • User wants maximum battery life during transport: Set lid close on battery → Hibernate
  • Power button accidentally pressed: Change power button action to "Do nothing" or "Ask me what to do" to prevent accidental shutdowns

Turn On Fast Startup

Fast Startup is a hybrid shutdown mode that combines elements of a traditional shutdown with hibernate. When Fast Startup is enabled and the user shuts down, Windows saves the kernel session and device driver state to a hibernate file — the user's session is fully closed (logged out), but the kernel state is preserved. The next boot loads this saved kernel state, skipping the full kernel initialization and making startup significantly faster.

Fast Startup — Important Caveats

Fast Startup is not a full shutdown. Because the kernel state is preserved, Fast Startup does not clear driver state or re-initialize hardware. This causes two common issues: (1) Windows updates that require a full reboot to complete will not apply on a "shutdown" with Fast Startup — they require selecting Restart instead, which does perform a full shutdown/boot cycle. (2) Dual-boot systems: Windows' Fast Startup locks the NTFS filesystem from the previous session, preventing Linux from safely reading/writing the Windows partition. Disable Fast Startup when dual-booting with Linux. Located: Power Options → Choose what the power buttons do → check "Turn on fast startup."

USB Selective Suspend

USB Selective Suspend allows Windows to place individual USB ports into a low-power suspended state when the connected device is idle, rather than maintaining continuous power to all USB ports at all times. The USB host controller can suspend individual ports independently without affecting other active ports.

  • Where to configure: Power Options → Change plan settings → Change advanced power settings → USB Settings → USB Selective Suspend Setting → Enabled/Disabled. Each power plan has its own setting, configurable separately for On Battery and Plugged In
  • Enabled (default): USB devices may be suspended when idle — reduces battery drain; beneficial for laptops; devices resume quickly when accessed
  • Disabled: USB ports maintain constant power; recommended when connected USB devices (audio interfaces, MIDI controllers, external drives, precision mice) experience intermittent disconnections, audio dropouts, or other issues related to power state transitions
  • Troubleshooting USB devices that randomly disconnect: Disable USB Selective Suspend as a first step — this is a very common cause of intermittent USB audio interface failures, external drive disconnections, and USB hub issues
  • Device Manager alternative: USB selective suspend can also be disabled per-device via Device Manager → Universal Serial Bus controllers → USB Root Hub → Properties → Power Management → uncheck "Allow the computer to turn off this device to save power"

Exam Focus — Power Options

Sleep = RAM powered, instant resume, low power draw. Hibernate = RAM to disk (hiberfil.sys), zero power, slower resume, requires free disk space equal to RAM. Standby = Sleep in older Windows terminology. Fast Startup = hybrid shutdown that preserves kernel state — NOT a true full shutdown; use Restart for full reboot. USB Selective Suspend = disable when USB devices randomly disconnect. Power plan High Performance = CPU at max always; Power Saver = minimum CPU frequency. Lid close action = Do nothing for clamshell desktop mode.

SECTION 3Windows Settings App

The Settings app (Win+I) is the modern replacement interface that Microsoft is building out to eventually replace Control Panel. It is organized into top-level categories, each containing related settings grouped logically. Settings mirrors and overlaps with Control Panel in many areas — both interfaces can reach many of the same underlying settings, just via different navigation paths.

Ease of Access

Settings → Ease of Access  |  Win+I → Ease of Access  |  Win+U

Ease of Access groups all accessibility features for users with vision, hearing, and motor impairments. These settings can also be opened at the login screen (bottom-right accessibility icon) for users who need them before signing in.

Vision — Narrator Screen reader that reads aloud the text of what appears on screen and describes events (notifications, key presses). Uses keyboard shortcuts starting with Caps Lock or Insert as the "Narrator key." Enable via Win+Ctrl+Enter or the toggle in Ease of Access. Essential for users with visual impairments or blindness.
Vision — Magnifier Enlarges portions of the screen. Three modes: Full screen (magnifies entire display), Lens (magnifier follows the mouse cursor), Docked (a panel at the top magnifies an area). Enable/adjust with Win++ (zoom in) and Win+- (zoom out). Win+Esc exits Magnifier.
Vision — High Contrast Replaces the color scheme with high-contrast themes (white-on-black or black-on-white) for users with low vision or color blindness. Toggle with Left Alt+Left Shift+Print Screen. High contrast themes apply to the entire OS and all applications.
Hearing — Captions / Visual Alerts Enables visual cues for audio alerts — screen flash instead of or in addition to audio beep. Closed captions settings control font, size, color, and background for video captioning. Important for users who are deaf or hard of hearing working in environments where audio output isn't reliable.
Interaction — Keyboard Sticky Keys: allows pressing keyboard shortcuts one key at a time instead of simultaneously (useful for users who cannot hold multiple keys at once). Enable by pressing Shift 5 times rapidly. Filter Keys: slows down keyboard repeat rate to ignore brief or repeated keystrokes. Toggle Keys: audio beep when Caps Lock, Num Lock, or Scroll Lock is pressed.
Interaction — Mouse Keys Enables using the numeric keypad to control the mouse pointer — an alternative to a physical mouse for users with motor impairments. Enable with Left Alt+Left Shift+Num Lock. Mouse Keys can interfere with number entry when accidentally activated — a common support call where a user's Num Lock keypad moves the cursor instead of typing numbers.

Time and Language

Settings → Time and Language  |  Win+I → Time & Language
Date and Time Set date and time manually or enable "Set time automatically" via NTP (Network Time Protocol) — the time server is configurable (default: time.windows.com). Enable "Set time zone automatically" for traveling devices. Incorrect time causes SSL/TLS certificate validation failures (certificates have validity periods validated against the system clock), Kerberos authentication failures on domain networks, and log correlation problems.
Region Sets the country/region which determines date format (MM/DD/YYYY vs. DD/MM/YYYY), number format (1,234.56 vs. 1.234,56), currency symbol, and measurement units. Important in multinational organizations where incorrect regional settings cause application data entry errors (dates entered in wrong format, comma vs. period in numbers).
Language Add display languages (changes UI language of Windows and Office), input methods (keyboard layouts — QWERTY, AZERTY, Dvorak), and speech recognition languages. Adding an input method adds an input language indicator to the taskbar; users can switch keyboard layouts with Win+Space. Phantom character input (wrong characters typed) is often caused by accidentally switching keyboard layout.
Speech Configures Windows Speech Recognition and Cortana's voice model. Training the speech model improves recognition accuracy for the specific user's voice and accent. Speech settings also control the text-to-speech voice (Microsoft David, Zira, or third-party voices) and speaking rate used by Narrator and other TTS applications.

Update and Security

Settings → Update & Security  |  Win+I → Windows Update
Windows Update Check for, download, and install updates. View update history. Pause updates for up to 35 days (Pro/Enterprise). Configure active hours (time range when Windows won't automatically restart for updates — protecting active working hours). Advanced options include enabling/disabling updates for other Microsoft products (Office) and choosing when feature updates are received (deferral policies in Enterprise).
Windows Security Opens Windows Security (formerly Windows Defender) — the integrated antivirus, firewall, and security health dashboard. Sections: Virus & threat protection (scan controls, real-time protection, update virus definitions), Firewall & network protection, App & browser control (SmartScreen, exploit protection), Device security (Secure Boot, TPM status, Core isolation/Memory Integrity), and Device performance & health.
Backup Links to File History (automated backup of user files to an external drive or network location — versioned copies of files saved at configurable intervals) and the legacy Windows Backup tool. File History is the recommended personal backup solution on Windows 10/11 for user data. For full system backup, use third-party imaging tools (Macrium Reflect, Veeam Agent).
Recovery Options for resetting Windows ("Reset this PC" — keep files or remove everything), advanced startup (boot to WinRE for repair tools), and returning to a previous version of Windows (available for a limited time after a major upgrade). "Reset this PC → Remove everything" is equivalent to a clean install and is the fastest way to prepare a machine for decommission or reissue.
Activation Shows Windows activation status and allows re-entering the product key or troubleshooting activation errors. Common activation issues: hardware changes (motherboard replacement) can trigger re-activation; volume licensing activation requires the KMS (Key Management Service) server to be reachable; digital license activation fails if Microsoft account is disconnected. Run slui.exe or slmgr /ato commands for activation management.

Personalization

Settings → Personalization  |  Right-click Desktop → Personalize
  • Background: Set desktop wallpaper (solid color, picture, or slideshow). In enterprise environments, Group Policy often locks this to prevent changes and enforce branding
  • Colors: Accent color for UI elements; light vs. dark mode for Start menu, taskbar, and apps. Dark mode enables the Windows 10/11 dark theme — individual applications must also support dark mode to fully apply it
  • Lock Screen: Sets the lock screen image (picture, slideshow, or Windows Spotlight — rotating Bing images). Controls which apps display status on the lock screen (calendar, mail preview)
  • Themes: Bundles wallpaper, color, sound scheme, and mouse cursor settings into a single named package. Microsoft provides additional themes in the Store. Corporate environments deploy custom themes via Group Policy
  • Start: Configure how many pinned and recent apps appear, whether recently added apps show, whether most used apps appear in Start. Show or hide specific folders on Start (Settings, File Explorer, Documents, Downloads, Music, Pictures, Videos, Network, Personal Folder)
  • Taskbar: Configure taskbar position, pinned items, system tray icons, and notification badge behavior. Lock the taskbar to prevent accidental repositioning. Enable/disable features like Search, Task View, News and Interests, and Cortana on the taskbar

Apps

Settings → Apps  |  Win+I → Apps
Apps and Features Lists all installed applications with options to uninstall or modify — the Settings app equivalent of Programs and Features in Control Panel. Also provides "Advanced options" for Store apps (reset, repair, background permissions, notifications). Clicking an app → Uninstall is the simplest path for most users, though Control Panel's Programs and Features is still preferred by technicians for its additional information (install date, version, publisher).
Default Apps Sets which application handles each file type or protocol by default: default browser, email client, music player, video player, photo viewer, and map application. Also "Choose default apps by file type" (e.g., associate .pdf files with Adobe Reader instead of Edge) and "Choose default apps by protocol" (e.g., which app opens mailto: links). In Windows 11, setting defaults requires manually selecting each file type — a deliberate Microsoft friction point to make Edge and Microsoft apps harder to replace.
Startup Apps Replaces the Startup tab in Task Manager for managing applications that launch at login. Toggle individual startup items on/off. Shows the "Startup impact" rating (Low/Medium/High) indicating how much the app slows login time. Equivalent to the Startup tab in Task Manager (taskmgr) — either interface can be used.
Optional Features Add or remove optional Windows features like Notepad, WordPad, RSAT (Remote Server Administration Tools — lets technicians manage Windows Server from a client machine without logging in to the server), Windows Media Player, OpenSSH client and server, and fonts. RSAT tools are critical for enterprise IT technicians.

Privacy

Settings → Privacy  |  Win+I → Privacy

Privacy settings control which applications and Windows components can access hardware features and user data. These are critically important both for user privacy and for troubleshooting applications that fail to access expected hardware resources.

Privacy — Key Permission Controls
General
Controls advertising ID (allows apps to show personalized ads), tracking app launches (for Start suggestions), suggested content in Settings, and sending diagnostic data to Microsoft. "Diagnostic data" setting has two levels: Required (basic telemetry only) and Optional (full telemetry including browsing and app usage data). Enterprise environments typically set this to Required via policy.
Camera
Master switch for camera access plus per-app controls. If a video conferencing app (Teams, Zoom) cannot access the camera, check here first — the app may have been denied camera access. "Allow apps to access your camera" must be on, AND the specific app must be allowed. Classic scenario: "camera works in one app but not another" → check per-app camera permission.
Microphone
Same structure as Camera — master microphone access toggle plus per-app permissions. Common troubleshooting: user's microphone works in Windows Sound settings (recording tab shows signal) but not in Teams or Zoom → check Privacy → Microphone; the app may be denied microphone access. Desktop apps (Win32, .exe files) are listed separately from Store apps.
Location
Controls whether Windows and apps can access GPS/location data. Default location can be set manually. Apps like Maps, weather widgets, and browser-based location services use this. On laptops without GPS, Windows uses Wi-Fi access point data and IP geolocation for approximate location. Disabling location blocks all location-based app functionality.
Background Apps
Controls which apps can run in the background (checking for updates, receiving notifications, syncing data) when not in focus. Disabling background access for an app means it won't send notifications or sync when the app isn't open. Useful for reducing battery drain and system resource use on low-powered devices.
Diagnostics and Feedback
Controls the level of diagnostic data (telemetry) sent to Microsoft, feedback frequency, and the diagnostic data viewer. Enterprise environments use Group Policy to enforce Required telemetry level and disable user modification of these settings.

System (Settings App)

Settings → System  |  Win+I → System
Display Screen resolution, refresh rate, orientation (landscape/portrait), brightness and color settings, Night Light (reduces blue light in evenings), HDR settings, and multi-monitor arrangement. Scale and layout (text size / DPI scaling) adjusts the size of text and UI elements — 100% is native resolution; 125% and 150% are common on high-DPI screens (HiDPI). Blurry applications on HiDPI screens often need their per-application DPI override set via right-click → Properties → Compatibility → DPI settings.
Notifications and Actions Enable/disable notifications globally and per-application. Configure which quick-action buttons appear in the Action Center (notification panel). Set focus assist levels — focus assist suppresses notifications during presentations, gaming, or defined quiet hours. Disabling all notifications is appropriate for kiosk systems; per-app control is better for personal workstations.
Storage Shows disk usage breakdown by category (System and reserved, Apps and games, Documents, Pictures, Videos, etc.). Storage Sense — automated storage cleanup that deletes temporary files, clears Downloads folder at intervals, and empties Recycle Bin automatically. Run Storage Sense manually to free space. "Change where new content is saved" redirects future Downloads, Documents, Music, Pictures, and Videos to a secondary drive — useful when the C: drive is nearly full.
Multitasking Snap layouts — configure Snap Assist behavior (automatically suggesting windows to fill alongside a snapped window, showing snapped apps when hovering over the taskbar). Virtual desktops settings — whether taskbar shows windows from all desktops or only current desktop. Alt+Tab behavior for virtual desktops.
About Shows Windows edition, version, build number, installation date, device name, processor, RAM, system type, and product ID. Links to "Advanced system settings" (sysdm.cpl), "Rename this PC," BitLocker, and Device Manager. Devices (Settings App)

Settings → Devices  |  Win+I → Devices
  • Bluetooth and other devices: Pair and manage Bluetooth devices; add printers, scanners, and other peripherals. For printers, this is the simpler path vs. Control Panel → Devices and Printers — though for advanced printer management (port configuration, security, spooler) the Control Panel path is still necessary
  • Printers and Scanners: Add printers (wizard-based), set default printer, "Let Windows manage my default printer" toggle, remove printers. Clicking a printer → Manage opens a simplified print queue and printing preferences interface
  • Mouse: Button configuration (left/right swap), pointer speed, scrolling behavior (lines per scroll notch, scroll inactive windows on hover). "Additional mouse options" opens the classic Mouse Properties control panel for advanced settings (pointer schemes, pointer trails, click speed)
  • Typing: Autocorrect and spell-check settings, hardware keyboard settings (toggle keys, filter keys, sticky keys shortcuts), touch keyboard behavior, voice typing settings

  • AutoPlay: Configures automatic actions when removable media (USB drives, optical discs, SD cards, cameras) are inserted. Network and Internet (Settings App)

Settings → Network & Internet  |  Win+I → Network & Internet
  • Status: Shows current network connection status, data usage, network troubleshooter, and links to advanced network settings (including Change adapter options and Network and Sharing Center)
  • Wi-Fi: Connect to Wi-Fi networks, manage known networks (forget networks), Wi-Fi Calling settings, hotspot 2.0 settings. "Show available networks" shows the same network list as clicking the taskbar Wi-Fi icon
  • Ethernet: View connection status, configure IP settings (DHCP or manual IP), DNS settings (DNS over HTTPS in Windows 11), and set the network profile (Private/Public)

Gaming

  • Xbox Game Bar: Enable/disable the Game Bar overlay (Win+G). Game Bar provides fps counter, performance overlay, screen recording, and screenshot tools. Some enterprise environments disable Game Bar via Group Policy to prevent misuse during work hours or to reduce system overhead

Hide extensions for known file types is a security risk — an EXE disguised with a PDF icon and named file.pdf.exe shows as file.pdf. Always uncheck this. Always show extensions on any computer you manage.

Device Manager: Yellow exclamation = bad/missing driver. Red X / down arrow = disabled. Unknown device = no driver. Roll Back Driver = device broke after driver update. Show Hidden Devices = see disconnected hardware.

Sleep ≠ Hibernate: Sleep keeps RAM powered (instant resume, loses data if power fails). Hibernate writes RAM to disk and powers off completely (slower resume, survives power loss). Standby = Sleep in older Windows terminology.

Fast Startup is NOT a full shutdown — it preserves kernel state in a hibernate file. Windows Updates requiring a reboot must use Restart, not Shutdown. Disable Fast Startup for dual-boot Linux configurations.

UAC: Standard User accounts get UAC prompts for admin actions. Running as admin all the time is a security risk. UAC should remain at default level or higher — never set to "Never notify."

Programs and Features → Turn Windows features on/off is where Hyper-V, WSL, Telnet Client, and .NET Framework versions are enabled/disabled — these are Windows OS components, not applications, and don't appear in the main program list.

Administrative tools exam priority: Know devmgmt.msc, diskmgmt.msc, services.msc, eventvwr.msc, compmgmt.msc, msconfig.exe, and regedit.exe by heart — these appear in nearly every domain of A+ troubleshooting questions.
