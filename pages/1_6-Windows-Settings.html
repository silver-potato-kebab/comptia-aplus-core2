Configure Microsoft Windows Settings

Objective 1.6 Domain weight: 28% Control Panel Applets · File Explorer Options · Power Options · Settings App

OVERVIEWIntroduction to Windows Configuration Interfaces

Windows configuration is split across two overlapping interfaces that have coexisted for years: the classic Control Panel, with its individual applets, and the modern Settings app, organized into broad categories. Microsoft has been migrating functionality from the former into the latter for years, but neither has fully replaced the other — a technician needs to know both, and needs to know roughly where a given configuration option lives regardless of which interface a specific version of Windows happens to surface it through.

This objective covers four groups. The first is the set of classic Control Panel applets named directly in the objective. The second and third are two specific applets broken out with their own detailed sub-bullets — File Explorer Options and Power Options — because each has several individually testable settings. The fourth is the list of top-level categories in the modern Settings app.

Core Concept — Two Interfaces, One Underlying System

Many settings in this objective can be reached through both the Control Panel and the Settings app, or have migrated from one to the other across Windows versions. The exam's expectation isn't that a setting lives in exactly one place forever — it's that you know what the setting does and can locate it in whichever interface a given scenario or Windows version presents. Focus on the purpose of each item first; the exact click-path is secondary.

SECTION 1Control Panel Applets

These are the classic, individually named Control Panel items a technician is expected to recognize and know how to use.

Internet Options

Configures Internet Explorer/legacy browser settings still used by some system components — security zones, connections, privacy settings, and default home page — even on systems where IE itself isn't the primary browser.

Devices and Printers

Lists all connected devices and printers, allowing installation, removal, setting a default printer, and accessing device-specific settings and troubleshooters.

Programs and Features

Lists installed applications and Windows features, allowing uninstallation, modification, or repair of installed software, and enabling/disabling optional Windows features.

Network and Sharing Center

Displays active network connections and status, and provides access to adapter settings, sharing options, and troubleshooting for network connectivity (Objective 1.7).

System

Displays core system information (OS edition, processor, installed RAM, computer name) and provides access to system protection, remote settings, and advanced system properties.

Windows Defender Firewall

Configures the built-in Windows firewall — enabling/disabling per network profile, managing allowed apps, and configuring advanced inbound/outbound rules (Objective 2.2).

Mail

Configures Outlook mail profiles and data files when Outlook is installed — managing email account settings outside of the Outlook application itself.

Sound

Manages audio playback and recording devices, sets the default input/output device, and adjusts levels and communication settings.

User Accounts

Manages local user account settings, changes account type, manages credentials, and configures User Account Control (UAC) behavior (Objective 2.2).

Device Manager

Also directly accessible via devmgmt.msc (Objective 1.4) — the same hardware/driver management console reachable through Control Panel.

Indexing Options

Configures which locations Windows Search indexes for faster file search results, and allows rebuilding the search index if search results become unreliable or incomplete.

Administrative Tools

A folder providing quick access to many of the MMC snap-ins and advanced utilities covered in Objective 1.4 (Event Viewer, Task Scheduler, Performance Monitor, and more) from a single central location.

SECTION 2File Explorer Options

File Explorer Options (sometimes still labeled Folder Options) controls how File Explorer displays and behaves — a frequently used applet for both everyday customization and specific troubleshooting/security tasks.

View hidden files Toggles whether files and folders marked with the "hidden" attribute are displayed in File Explorer — commonly needed when troubleshooting, since many system and configuration files are hidden by default to prevent accidental modification or deletion.
Hide extensions Controls whether file extensions (.exe, .docx, .txt) are shown or hidden for known file types. Disabling this (i.e., showing extensions) is a frequently recommended security practice, since malware often disguises itself with a deceptive filename like invoice.pdf.exe that appears to be a harmless PDF when extensions are hidden.
General options Controls broader File Explorer behavior — whether items open with a single or double click, whether folders open in the same window or a new one, and default Quick Access/navigation pane behavior.
View options Controls additional display settings beyond hidden files and extensions — showing/hiding protected operating system files, displaying full paths in the title bar, showing file size information in folder tips, and similar display preferences.

Exam Angle — Hide Extensions as a Security Control

A scenario describing a user who was tricked into running a malicious file that "looked like" a normal document is very likely pointing at hidden file extensions as a contributing factor. The corrective action — disabling "hide extensions for known file types" so the true, full filename (including its real extension) is always visible — is a frequently tested File Explorer Options detail with direct security implications, not just a cosmetic preference.

SECTION 3Power Options

Power Options governs how a Windows machine manages power consumption and transitions between full-power and reduced-power states — especially relevant for laptops, but applicable to desktops as well.

Power States

Power States — Lowest to Highest Power Savings
1
Sleep/SuspendSystem state and open work are kept in RAM, which continues drawing a small amount of power; the machine resumes almost instantly since nothing needs to be reloaded from disk
2
StandbyFunctionally similar to sleep — a reduced-power state that preserves RAM contents for a fast resume, with terminology varying somewhat by Windows version and hardware
3
HibernateThe current system state is written from RAM to disk, and the machine powers off completely — draws effectively no power while hibernating, but takes longer to resume than sleep since the saved state must be read back from disk
Power plans Predefined (or custom) sets of power management rules — screen timeout, sleep timeout, processor performance — bundled together as a single selectable profile (e.g., Balanced, Power saver, High performance), letting a user switch their overall power behavior with one selection rather than adjusting each setting individually.
Choose what closing the lid does A laptop-specific setting controlling the action taken when the lid is closed — sleep, hibernate, shut down, or do nothing — separately configurable for when the machine is on battery versus plugged in.
Turn on fast startup A hybrid shutdown feature that saves the OS kernel session to disk (similar to hibernation) when the system is shut down, allowing subsequent boots to be significantly faster — but this can occasionally interfere with certain low-level troubleshooting steps or hardware changes that expect a true full shutdown/cold boot.
USB selective suspend A power-saving feature that allows Windows to selectively suspend individual USB devices when not actively in use, reducing overall power draw — occasionally a troubleshooting culprit when a USB device disconnects or misbehaves after a period of inactivity, since the device was suspended rather than genuinely failing.

Fast Startup and USB Selective Suspend — Common Troubleshooting Culprits

Both of these features are common, non-obvious causes of confusing symptoms. Fast startup can cause a "shutdown" to behave more like hibernation, which occasionally interferes with driver or hardware changes that expect a genuine cold boot to take effect — disabling it is a reasonable troubleshooting step when a hardware change doesn't seem to be recognized after a restart. USB selective suspend can cause a USB device (particularly external drives or certain peripherals) to appear to disconnect or stop responding after sitting idle — disabling it for a specific device is a reasonable step when troubleshooting intermittent USB dropouts.

SECTION 4Windows Settings App Categories

The modern Settings app (accessible via Win + I) organizes configuration into broad top-level categories, many of which now house settings that used to live exclusively in Control Panel.

Ease of Access

Accessibility features — narrator, magnifier, high contrast, closed captions, and other accommodations

Time and Language

Date/time, region, and display/input language settings

Update and Security

Windows Update, recovery options, backup, and built-in security/Defender settings

Personalization

Desktop background, colors, lock screen, themes, taskbar, and Start menu appearance

Apps

Installed application management, default apps, and optional feature installation

Privacy

App permissions — camera, microphone, location — and general data/diagnostics privacy controls

System

Display, sound, notifications, power/battery, storage, and general "About" system info

Devices

Bluetooth, printers/scanners, mouse, and other connected peripheral settings

Network and Internet

Wi-Fi, Ethernet, VPN, proxy, and general network status settings

Gaming

Game Bar, game mode, captures, and gaming-specific performance settings

Accounts

Sign-in options, other user accounts, syncing settings, and Microsoft account/work-or-school access

Same Concept, Two Interfaces — A Study Strategy

Notice that "System" and device/network management appear conceptually in both the Control Panel list (Section 1) and the Settings app list (Section 4), and Device Manager is directly reachable from both. Rather than memorizing two entirely separate universes of settings, it's more efficient to learn the underlying concept once (e.g., "how do I check installed RAM and computer name") and simply recognize that it might be reached via the Control Panel's System applet or the Settings app's System → About page depending on the Windows version and scenario described.

REFERENCEQuick Reference Cards

"Where Do I Configure This?" — Common Tasks

  • Set a default printer — Devices and Printers
  • Uninstall a program — Programs and Features
  • Show real file extensions — File Explorer Options → View
  • Check installed RAM/computer name — System applet or Settings → System → About
  • Adjust firewall rules — Windows Defender Firewall

Power State Quick Compare

  • Fastest resume, some power draw — Sleep/Suspend/Standby
  • No power draw, slower resume — Hibernate
  • Bundles timeout/performance rules — Power plan
  • Laptop-specific action on lid close — "Choose what closing the lid does"

Troubleshooting Culprits to Remember

  • Hardware change not detected after restart — check Fast Startup
  • USB device "disconnects" when idle — check USB selective suspend
  • User ran a disguised malicious file — check hidden extensions setting
  • Search results incomplete/stale — check/rebuild Indexing Options

  • Accessibility — Ease of Access
  • Wi-Fi/VPN/proxy — Network and Internet

Final Exam Reminders

Disabling "hide extensions for known file types" is a security-relevant setting, not just cosmetic — it prevents a file like invoice.pdf.exe from displaying as if it were a harmless PDF.

Hibernate writes RAM to disk and powers off completely; Sleep/Suspend/Standby keep RAM powered for a near-instant resume — the trade-off is always resume speed versus power savings, and this distinction is one of the most reliably tested Power Options facts.

Fast Startup and USB selective suspend are both common, non-obvious troubleshooting culprits — a hardware change not being detected after a restart, or a USB device that seems to vanish after being idle, should prompt checking these two settings specifically.

Device Manager and the System applet exist in both the Control Panel and Settings app worlds — don't treat the two lists in this objective as entirely separate; many concepts overlap or have simply moved between interfaces across Windows versions.

Power plans bundle multiple individual settings into one selectable profile — recognize a scenario asking to quickly switch overall power behavior (rather than adjust one specific setting) as a power plan question.

The eleven Settings app categories map roughly to older Control Panel functionality — know the general category a setting would fall under (e.g., app permissions → Privacy, not System) since the exam may ask which Settings category houses a described option.
