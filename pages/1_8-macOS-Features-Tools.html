OVERVIEWIntroduction

Objective 1.8 covers macOS — Apple's desktop operating system — as a parallel track to the Windows-focused objectives elsewhere in Core 2's Domain 1. The exam expects a technician to be conversationally fluent in macOS even if Windows is their primary platform, since real-world IT support frequently involves whatever operating system walks through the door.

This objective is broad and list-heavy by nature: application installation, the filesystem's folder structure, account/security concepts, the System Preferences panes, a long list of signature macOS features, and several standalone tools (Disk Utility, FileVault, Terminal, Force Quit). Rather than trying to memorize every item as an isolated fact, look for the underlying logic in each section — file types map to installation methods, system folders map to a scope-of-access principle, and most "features" map to a specific everyday user need.

PART 1Installation and Uninstallation of Applications

File Types

.dmg Disk image — a mountable virtual disk file, commonly used to distribute macOS applications. Double-clicking a .dmg mounts it as a virtual drive in Finder, typically revealing the application itself alongside a shortcut to the Applications folder, with installation simply being a matter of dragging the app icon into that Applications shortcut.
.pkg Installer package — a guided installer file, functioning more like a traditional Windows-style setup wizard, walking the user through installation steps (license agreements, install location, configuration choices) rather than a simple drag-and-drop. Common for more complex software or system-level components requiring multiple files placed in specific locations.
.app The actual application bundle itself — what appears to be a single file/icon in Finder is actually a structured folder containing all the application's executable code, resources, and supporting files, bundled together and presented to the user as one self-contained icon.

How These Three File Types Relate

A typical macOS software distribution flow: a developer packages their finished .app bundle inside a .dmg (for simple drag-to-install software) or a .pkg (for more complex, guided installation) for distribution. Once installed, the resulting application living in /Applications is the .app bundle itself — the .dmg or .pkg was just the delivery/installation mechanism, not the application's permanent, ongoing form.

App Store

The macOS App Store provides a centralized, Apple-curated source for downloading and installing applications, tied to the user's Apple ID. App Store installations are handled automatically by the OS (no .dmg/.pkg file handling required by the user), and updates for App Store-sourced apps are managed centrally through the App Store itself, similar in concept to the curated app store model on iOS/mobile devices.

Uninstallation Process

Unlike Windows, which generally requires running a dedicated uninstaller or using a centralized "Programs and Features" control panel, macOS applications are commonly uninstalled simply by dragging the .app bundle from the Applications folder to the Trash — since the application bundle is largely self-contained. Some more complex applications (particularly those that install system-level components, kernel extensions, or background services) provide their own dedicated uninstaller utility for a more thorough removal, since a simple drag-to-trash wouldn't necessarily clean up every associated file in those cases.

Exam Angle

Recognize the basic macOS uninstall pattern (drag to Trash) as fundamentally simpler than the Windows model, while also recognizing that this simple method doesn't always remove every trace of more complex software — leftover preference files and support files can remain in the user's Library folder (Part 2, below) even after the main application has been deleted.

PART 2System Folders

macOS organizes its filesystem around a small set of top-level folders, each with a distinct purpose and scope of access — understanding this structure is foundational to navigating, troubleshooting, and supporting a Mac.

Core macOS Folder Structure

/ApplicationsHolds installed applications available to all users on the Mac — the standard destination when installing via .dmg or .pkg.
/UsersContains each user account's individual home folder (e.g., /Users/jsmith), holding that specific user's Desktop, Documents, Downloads, and personal settings — analogous to C:\Users\ on Windows.
/LibraryThe system-wide Library, holding support files, preferences, and resources shared across all users on the Mac — distinct from each individual user's own Library (below).
/SystemContains the core macOS operating system files themselves. This folder is tightly protected by macOS's System Integrity Protection (SIP) and is not meant to be modified by users or most third-party software under normal circumstances.
/Users/[name]/LibraryEach individual user's personal Library folder, holding that specific user's application preferences, caches, and support files — hidden from Finder by default, but accessible when needed for troubleshooting.

Exam Angle — Two Different "Library" Folders

A frequently tested distinction: /Library (system-wide, affects all users) versus /Users/[username]/Library (specific to one individual user account). When troubleshooting an application issue affecting only one specific user account, the relevant preference/cache files are typically found in that user's personal Library, not the system-wide one — an important distinction when deciding where to look for corrupted preference files or leftover application data during troubleshooting.

PART 3Apple ID and Corporate Restrictions

An Apple ID is the central account tying together a user's access to the App Store, iCloud services, and various Apple ecosystem features — conceptually similar to a Microsoft account's role across Windows and Microsoft 365 services. In a managed/corporate environment, organizations can apply restrictions to how Apple IDs and associated services are used on company-owned devices — for example, restricting personal Apple ID sign-in on a corporate Mac, controlling which apps can be installed, or managing devices centrally through Apple's enterprise device management framework (a macOS/iOS parallel to the MDM concepts covered in objective 1.3).

PART 4Best Practices

Backups Regular backups protect against data loss from hardware failure, accidental deletion, or malware — on macOS, this is most commonly accomplished via the built-in Time Machine feature (covered in Part 6 below).
Antivirus While macOS includes built-in protective technologies, many business environments still deploy dedicated third-party antivirus/endpoint protection software on Macs as an additional layer of defense, particularly in environments with compliance requirements or mixed-OS security policies.
Updates/patches Keeping macOS and installed applications current with security patches and bug fixes, managed through System Preferences/Settings' Software Update section, is a fundamental best practice paralleling the same patching discipline expected on any operating system.
Rapid Security Response (RSR) A macOS mechanism for delivering critical, urgent security fixes outside the normal full OS update cycle — allowing Apple to patch serious, actively-exploited vulnerabilities quickly without requiring a full system update/restart cycle. RSR updates are typically smaller, faster to apply, and can sometimes be removed independently if they cause compatibility issues, unlike a full OS update.

Exam Angle

Recognize RSR specifically as a faster, lighter-weight, out-of-band patching mechanism distinct from regular full macOS updates — the key idea is urgency: RSR exists so Apple doesn't have to wait for the next full OS release cycle to patch a critical, actively-exploited security flaw.

PART 5System Preferences

System Preferences (renamed System Settings in more recent macOS versions, though both names remain in common use and are treated as equivalent for exam purposes) is the central control panel for configuring macOS — directly analogous to the Windows Control Panel/Settings app.

PART 6Features

Multiple desktops Allows a user to create several distinct virtual desktop "Spaces," each potentially holding different open applications/windows, switchable independently — useful for organizing work contexts (e.g., one Space for communication apps, another for focused project work).
Mission Control A visual overview feature showing all open windows, all active Spaces/desktops, and any full-screen apps at once, making it easy to see everything running and quickly navigate between windows/desktops.
Keychain macOS's built-in, encrypted credential manager — securely stores saved passwords, certificates, and secure notes, syncing across a user's devices when iCloud Keychain is enabled. Conceptually similar to a password manager, but deeply integrated into the OS itself.
Spotlight macOS's built-in system-wide search feature, allowing a user to quickly find files, launch applications, perform calculations, look up definitions, and more from a single, fast search interface — broadly analogous in role to Windows Search.
iCloud Apple's cloud service ecosystem, tied to the user's Apple ID, providing synchronization and cloud-based functionality across several sub-services: iMessage (text/multimedia messaging synced across Apple devices), FaceTime (Apple's video/audio calling service), and Drive (iCloud Drive, cloud file storage and synchronization, conceptually similar to other cloud storage services discussed in objective 1.3 and 3.7).
Gestures Multi-touch trackpad gestures (swipes, pinches, multi-finger taps) used throughout macOS for navigation — swiping between desktops/Spaces, pinching to zoom, three/four-finger swipes to trigger Mission Control, and similar trackpad-driven interactions that are a signature part of the macOS user experience.
Finder macOS's built-in file management application — the direct equivalent of Windows File Explorer — used for browsing the filesystem, managing files/folders, and accessing network shares.
Dock The customizable bar (typically positioned at the bottom of the screen) holding shortcuts to frequently used and currently running applications, providing quick access and visual indication of what's currently open — broadly analogous in role to the Windows taskbar.
Continuity A suite of features enabling seamless handoff and interaction between a user's Apple devices — for example, starting a task on an iPhone and continuing it on a Mac (Handoff), using an iPhone as a webcam, answering phone calls or texts from a Mac, or copying content on one device and pasting it on another (Universal Clipboard). Continuity is the umbrella concept describing this cross-device fluidity across the Apple ecosystem.

Windows Equivalents — A Mental Shortcut

Mapping unfamiliar macOS features to a Windows equivalent can help anchor them in memory: Finder ≈ File Explorer, Dock ≈ Taskbar, Spotlight ≈ Windows Search, Mission Control ≈ Task View, Keychain ≈ Credential Manager, iCloud ≈ OneDrive/Microsoft account ecosystem. These aren't perfect one-to-one matches, but the rough parallel is a useful starting point for remembering what each feature is fundamentally for.

PART 7Disk Utility

Disk Utility is macOS's built-in tool for managing storage drives and volumes — partitioning and formatting drives, verifying and repairing disk errors (similar in role to chkdsk on Windows), erasing drives securely, and creating/restoring disk images. It's a central go-to tool for storage-related troubleshooting and preparation tasks on a Mac, including preparing a drive before a clean OS installation.

PART 8FileVault

FileVault is macOS's built-in full-disk encryption feature, encrypting the entire startup disk's contents and requiring the user's account password (or a recovery key) to decrypt and access the data — the direct macOS equivalent of Windows BitLocker (objective 3.5). Once enabled, the disk's contents remain protected even if the physical drive is removed and accessed from another machine, since the data is unreadable without the correct decryption credential.

Exam Angle

Pair FileVault (macOS) directly with BitLocker (Windows) in your mental model — both are built-in, OS-level full-disk encryption features serving the same fundamental purpose, just on different platforms. A scenario describing the need to protect data on a lost or stolen Mac points to verifying FileVault is enabled.

PART 9Terminal

Terminal is macOS's command-line interface application, providing access to the underlying Unix-based shell environment that macOS is built on. Terminal allows a technician to run command-line utilities, scripts, and administrative tasks directly — the macOS equivalent in role (though built on a different underlying command set/shell) to Command Prompt or PowerShell on Windows.

PART 10Force Quit

Force Quit immediately terminates an unresponsive or frozen application, accessible via the Apple menu's "Force Quit" option, the keyboard shortcut Command + Option + Escape, or by right-clicking (or Control-clicking) an app's Dock icon. This is the direct macOS equivalent of using Task Manager to end a non-responsive process on Windows, serving as the standard first response when a specific application stops responding without requiring a full system restart.

Force Quit vs. Restarting the Mac

Force Quit targets and terminates only the specific unresponsive application, leaving the rest of the system and all other open applications completely unaffected — always the preferred first step over restarting the entire machine when only one application has frozen, since a full restart is more disruptive and unnecessary if the underlying OS itself is functioning normally.

Final Exam Reminders

.dmg = drag-to-install disk image. .pkg = guided installer. .app = the application bundle itself.

/Library = system-wide, all users. /Users/[name]/Library = that one user only. This distinction drives where to troubleshoot.

RSR = fast, critical security patches delivered outside the normal full-update cycle.

FileVault = macOS's full-disk encryption, directly parallel to Windows BitLocker.

Force Quit = ends one unresponsive app without restarting the whole Mac — always try this before a full restart.

Continuity = the umbrella term for cross-device handoff features across a user's Apple devices.

Map unfamiliar macOS terms to their Windows equivalent as a memory anchor — Finder/Explorer, Dock/Taskbar, Spotlight/Search, Keychain/Credential Manager.
