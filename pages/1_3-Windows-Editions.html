OVERVIEWIntroduction

Microsoft markets Windows in multiple distinct editions — versions of the same underlying operating system differentiated by their feature sets, licensing terms, and intended use cases. For an IT support technician, understanding which edition is installed on a given machine is not merely an academic exercise: it directly determines what tools you can use, what management capabilities are available, and what upgrade paths are open.

The exam tests two generations of Windows: Windows 10 and Windows 11. While the two share a common architectural foundation and many features, they differ in hardware requirements, edition lineup, and some interface elements. You need to know not only what features exist in each edition, but specifically which editions include features like BitLocker, Remote Desktop, Group Policy, and domain joining — and which do not.

How This Objective Is Tested

Expect scenario-based questions such as: "A user needs to join their Windows 10 computer to a corporate domain. They are currently running Windows 10 Home. What is the minimum edition they need?" You need to know the feature matrix — not just that features exist, but exactly which editions include them. The compare/contrast verb tells you that edition-to-edition differences are the core of this objective.

SECTION 1Windows 10 Editions

Windows 10, released in July 2015, is organized into four primary editions relevant to the A+ exam. Each edition is a superset of the one below it — meaning Pro includes everything Home offers, Pro for Workstations includes everything Pro offers, and so on. Mainstream support for Windows 10 ends October 14, 2025.

Windows 10 — Edition Overview
Home
Consumer edition. Pre-installed on most retail laptops and desktops sold to individuals. Supports Microsoft accounts and local accounts. No Group Policy editor, no BitLocker (only Device Encryption on compatible hardware), no domain join, no Remote Desktop host. Maximum RAM: 128 GB. Mandatory automatic updates with no deferral controls.
Pro
Professional/SMB edition. Everything in Home plus: domain join, Group Policy editor (gpedit.msc), BitLocker drive encryption, Remote Desktop Protocol (RDP) host, Windows Sandbox, Hyper-V, and update deferral controls (Windows Update for Business). Maximum RAM: 2 TB. The minimum edition for a business workstation joining a corporate Active Directory domain.
Pro for Workstations
High-performance hardware edition. Everything in Pro plus: support for Resilient File System (ReFS), Non-Volatile Dual Inline Memory Module (NVDIMM), persistent memory, and high-core-count processors like Intel Xeon and AMD EPYC/Threadripper. Supports up to 4 physical CPUs and up to 6 TB of RAM. Designed for content creation, scientific computing, and video production workstations — not typical office deployments.
Enterprise
Large organization edition. Everything in Pro plus: AppLocker (application whitelisting), DirectAccess, Credential Guard, Device Guard, Windows Defender Application Control, Long-Term Servicing Channel (LTSC) option, and Microsoft's advanced security features for managed deployments. Not available through retail — only through Microsoft Volume Licensing agreements (EA, EAS) or Microsoft 365. Maximum RAM: 2 TB (same as Pro). Used by enterprise IT environments that need the full suite of management and security features.

Exam Focus — What Sets Each Edition Apart

The key exam differentiators for Windows 10 editions are: Home lacks BitLocker, gpedit.msc, domain join, and RDP host. Pro adds all four. Pro for Workstations adds ReFS and extreme hardware support (4 CPUs, 6 TB RAM). Enterprise adds AppLocker and advanced security/management features and requires volume licensing. Know these four distinctions cold.

32-bit vs. 64-bit RAM Limits

32-bit (x86) versions of Windows are limited to 4 GB of RAM regardless of edition — a hardware addressing constraint, not a Microsoft licensing decision. The RAM figures in the table above apply to the 64-bit versions. Microsoft no longer offers 32-bit installations of Windows 11 at all.

SECTION 2Windows 11 Editions

Windows 11, released October 2021, consolidates the edition lineup to three primary editions for the A+ exam — dropping Pro for Workstations as a separate exam topic. The feature logic remains the same: Pro adds enterprise management features over Home; Enterprise builds further on Pro for large organizations.

Critically, Windows 11 raised the hardware bar significantly compared to Windows 10. All editions of Windows 11 share the same minimum hardware requirements, which are stricter than Windows 10 in meaningful ways — especially the mandatory requirement for TPM 2.0 and UEFI Secure Boot.

Windows 11 — Edition Overview
Home
Consumer edition. Pre-installed on most new consumer PCs. Requires a Microsoft account during setup (offline account setup has been progressively restricted in newer builds). Includes the redesigned Start menu (centered by default), Snap Layouts, Teams integration, and Android app support via Amazon Appstore. No BitLocker, no gpedit.msc, no domain join, no RDP host. Mandatory updates with limited deferral.
Pro
Professional edition. Everything in Home plus: domain join, Group Policy editor (gpedit.msc), BitLocker, Remote Desktop host, Hyper-V, Windows Sandbox, and update deferral controls. Local account setup is available during installation. The standard choice for business workstations. Maximum RAM: 2 TB. Supports 2 physical CPUs.
Enterprise
Large organization edition. Everything in Pro plus the full suite of enterprise security features: Credential Guard, Application Control for Business (formerly Device Guard), AppLocker, DirectAccess, and Windows Defender Application Guard. Available only through Volume Licensing. Also available in an LTSC variant for systems requiring long-term stability (medical devices, ATMs, industrial systems) that should not receive feature updates.

SECTION 3N Versions

Microsoft sells N versions of Windows editions specifically for the European market. These versions exist as a result of a 2004 European Commission antitrust ruling that found Microsoft illegally bundled Windows Media Player with its operating system. N versions are identical to their standard counterparts in every functional respect except that certain multimedia components are not included by default.

What "N" Stands For The "N" designation is sometimes said to stand for "Not with Windows Media Player," though Microsoft has never officially confirmed this etymology. The naming convention was simply assigned by the European Commission remedy.
What Is Removed N versions ship without Windows Media Player, the Movies & TV app, the Music app, Groove Music, and the related multimedia playback infrastructure. Since Windows 10, this has also affected some communications apps and voice features that depend on the media infrastructure.
Available N Editions N versions exist for Home, Pro, and Enterprise (both Windows 10 and 11). Example: Windows 10 Pro N, Windows 11 Home N.
Adding Media Features Back Users can install the free Media Feature Pack from Microsoft to restore the removed functionality. This restores Windows Media Player and the related playback components to an N version, making it functionally identical to the non-N edition.
Relevance for the Exam If you encounter an N version in a support scenario, know that missing multimedia functionality is by design, not a corruption or driver issue. The fix is to install the Media Feature Pack, not to reinstall Windows.

KN Editions

A parallel "KN" designation exists for Windows sold in South Korea, also resulting from an antitrust ruling. KN editions similarly exclude Windows Media Player and certain messaging apps. The A+ exam focuses on N versions, but KN versions function identically in terms of the multimedia exclusion.

SECTION 4Feature Differences

The exam focuses specifically on six key features that differ across Windows editions. Understanding these differences determines which edition a given scenario calls for, and what is or isn't available to you as a technician.

Domain vs. Workgroup

Every Windows computer participates in one of two network organization models: a workgroup or a domain. The distinction is fundamental to enterprise IT management and is one of the most exam-relevant feature differences between editions.

Workgroup A peer-to-peer network model where each computer manages its own local user accounts, security policies, and resources independently. There is no central authority. Each machine stores its own Security Account Manager (SAM) database. Suitable for small environments (up to ~10–20 computers). All Windows editions can join a workgroup. No server infrastructure required.
Domain A client-server network model where a central server running Active Directory Domain Services (AD DS) — a Domain Controller (DC) — manages authentication, user accounts, and security policy for all joined computers. Users log in with domain credentials and receive centrally-managed Group Policy settings. Domain join is available only in Pro, Pro for Workstations, and Enterprise — not Home. Requires Windows Server infrastructure.

Exam Focus — Domain Join Edition Requirement

A technician is deploying 50 workstations for a company using Active Directory. The machines came pre-installed with Windows 10 Home. The technician cannot join them to the domain. The correct solution is to upgrade to at least Windows 10 Pro. Home editions — Windows 10 and Windows 11 — do not support domain join. This is one of the most commonly tested scenarios on the exam.

Desktop Styles / User Interface

While all editions of a given Windows version share the same underlying interface, there are meaningful UI differences between Windows 10 and Windows 11 that you should recognize in exam scenarios or when supporting users.

Windows 10 Start Menu The Start menu expands from the lower-left corner. It presents a two-panel layout: a narrow left rail with user icon, power, Settings, and pinned app icons; and a right section with Live Tiles — resizable dynamic tiles that can display app content (news, weather, calendar). Users can resize and rearrange tiles.
Windows 11 Start Menu Redesigned with the taskbar and Start button centered by default (though it can be moved to the left in Settings). Live Tiles are gone, replaced by a cleaner grid of pinned app icons and a "Recommended" section showing recent files and apps. More focused and visually simplified.
Windows 11 Snap Layouts Hovering over a window's maximize button reveals a Snap Layout overlay with multiple arrangement options (side-by-side, quadrant, etc.). This is a Windows 11 feature not present in Windows 10 (though Windows 10 has snap-to-corner via dragging).
Taskbar Behavior In Windows 11, the taskbar cannot be moved to the top or sides of the screen (a change from Windows 10 where repositioning was supported). The system tray and notification behavior also changed — the date/time area, volume, and network icons behave differently in Win11.
Right-Click Context Menu Windows 11 introduced a simplified right-click context menu that shows a compact set of icons for common actions (cut, copy, rename, delete, share) and hides less-used options under "Show more options." Windows 10 uses the traditional, longer context menu by default.

From the exam perspective, interface differences are less heavily tested than feature availability, but you should be able to recognize screenshots of Windows 10 versus Windows 11 based on the Start menu placement, taskbar appearance, and overall design language.

Availability of Remote Desktop Protocol (RDP)

Remote Desktop Protocol (RDP) is Microsoft's proprietary protocol that allows a user to remotely control a Windows desktop graphically over a network. It operates on port 3389 by default. The exam distinguishes between two RDP roles: host (the computer being controlled) and client (the computer doing the controlling).

Critical Distinction: RDP Client vs. RDP Host

Every edition of Windows can connect to (act as a client for) a Remote Desktop session using the built-in Remote Desktop Connection app (mstsc.exe). The edition restriction only applies to hosting an RDP session — allowing others to connect to that machine. Windows Home cannot host RDP connections. This is one of the most mis-remembered exam facts — read questions carefully to distinguish "connect to" vs. "be connected to."

Home (Win 10 & 11) Client only. Can connect outbound to remote desktops. Cannot host inbound RDP connections. The "Remote Desktop" toggle in Settings → System → Remote Desktop is either absent or greyed out.
Pro, Pro for Workstations, Enterprise Client and host. Can both connect to and host Remote Desktop sessions. Enabled via: Settings → System → Remote Desktop → toggle "Enable Remote Desktop" to On. Requires a password on the account being connected to.

When Remote Desktop hosting is enabled on Pro or Enterprise, the system accepts connections via RDP on TCP port 3389. For remote support scenarios, a technician connecting to a user's computer requires that the user's machine be running at least Windows Pro. Alternatively, third-party tools (TeamViewer, AnyDesk, Quick Assist) work across all editions.

RAM Support Limitations

As established in the editions sections above, Windows imposes per-edition RAM ceilings that interact with processor architecture limits. The exam expects you to know the key numbers:

Windows 10

  • Home: 128 GB max
  • Pro: 2 TB max
  • Pro for Workstations: 6 TB max
  • Enterprise: 2 TB max

Windows 11

  • Home: 128 GB max
  • Pro: 2 TB max
  • Enterprise: 2 TB max

In practical terms, the 128 GB Home limit is not a real-world constraint for consumer hardware — current consumer platforms typically max out well below that. The distinction matters most when determining which edition is appropriate for a high-memory workstation (a video editor or engineer building a system with 256 GB+ of RAM would need Pro or Enterprise, not Home).

BitLocker

BitLocker is Microsoft's full-volume encryption technology that encrypts entire drive volumes using AES encryption. It is designed to protect data at rest — if a laptop is stolen or a drive is removed, the encrypted data is inaccessible without the recovery key or the original system's TPM.

Edition Availability Pro, Pro for Workstations, and Enterprise only. Home editions do not include BitLocker. This is a firm, exam-tested fact. Windows 10 and 11 Home offer a limited alternative called Device Encryption (a simplified form of BitLocker that automatically encrypts the system drive on qualifying hardware), but this is not the same as the full BitLocker management interface.
BitLocker vs. Device Encryption Device Encryption (Home) automatically enables silently and is managed through Settings. It requires a Microsoft account to back up the recovery key to OneDrive, a Modern Standby-capable device, and a TPM. BitLocker (Pro+) provides the full feature set: encrypt any drive (not just the system drive), manage via Group Policy or the BitLocker Drive Encryption control panel, pre-boot authentication, network unlock, and recovery key management in Active Directory.
BitLocker-To-Go A BitLocker variant that encrypts removable drives (USB flash drives, external HDDs). Available in Pro and Enterprise. The encrypted drive can be read on any Windows system with the correct password or recovery key. Home users can read a BitLocker-To-Go encrypted drive (they are prompted for the password), but cannot encrypt removable media using BitLocker-To-Go.
TPM Requirement BitLocker's default configuration stores the encryption key in the computer's Trusted Platform Module (TPM). The TPM seals the key to the system's hardware state — if the drive is moved to a different PC (without the recovery key), the TPM won't release the key and the drive stays encrypted. BitLocker can be configured to run without a TPM using a USB startup key, but this is a non-default configuration requiring a Group Policy change.

Exam Focus — BitLocker Edition Requirement

BitLocker is Pro and Enterprise only. If a Home user asks you to set up full-drive encryption using BitLocker, the answer is that they must first upgrade to at least Windows Pro. On the exam, scenarios about encrypting a lost or stolen laptop almost always involve BitLocker, and the "gotcha" is whether the machine is running Home (can't use it) or Pro (can).

gpedit.msc — Group Policy Editor

The Local Group Policy Editor (gpedit.msc) is a Microsoft Management Console snap-in that provides a graphical interface for modifying thousands of Windows configuration settings that are not exposed through the standard Settings app or Control Panel.

Edition Availability Pro, Pro for Workstations, and Enterprise only. Attempting to run gpedit.msc on a Home edition produces an error: "Windows cannot find 'gpedit.msc'." The Local Group Policy Editor is simply not installed on Home editions.
What It Controls Local Group Policy manages settings for Computer Configuration (system-wide) and User Configuration (per-user). Categories include: security settings, software restrictions, Windows Update behavior, startup/shutdown scripts, network settings, user rights, and thousands of individual application and OS behavior settings.
Local vs. Domain Group Policy When a machine is joined to a domain, Group Policy settings from the Domain Controller override local Group Policy settings. The domain administrator can push policy to all domain-joined computers centrally. Local Group Policy (gpedit.msc) applies only to settings on the local machine and is used in standalone Pro/Enterprise scenarios or in conjunction with domain policy.
Common Technician Uses Disabling removable storage, enforcing password complexity, configuring Windows Update behavior, enabling or disabling features not accessible via Settings, restricting access to Control Panel, and configuring User Account Control (UAC) behavior.

Registry as an Alternative on Home

Many Group Policy settings correspond to specific Registry keys. On Home editions where gpedit.msc is unavailable, an administrator can sometimes achieve the same result by directly editing the Registry using regedit.exe. However, this is riskier (no error checking), less discoverable, and not appropriate in exam scenarios — the correct answer to "how do I configure Group Policy" on Home is "you can't — upgrade to Pro."

SECTION 6Upgrade Paths

When a user or organization needs to move to a newer or higher-tier edition of Windows, there are two fundamentally different approaches: an in-place upgrade and a clean install. Understanding when each is appropriate and what is preserved or lost in each approach is essential for exam scenarios.

In-Place Upgrade

An in-place upgrade installs a new version of Windows over the existing installation while preserving user data, applications, and settings. The user's documents, installed programs, and personal settings are migrated to the new OS automatically. The machine is bootable and operational before the upgrade and remains so after — with the new OS in place.

Preserved during in-place upgrade Personal files and documents, installed applications (if compatible), user account settings, browser history and favorites, desktop background and personalization settings, and most installed drivers.
What may be affected Some applications may not work after the upgrade if they are incompatible with the new OS version. Windows Defender settings may reset. Some settings are migrated imperfectly. The old Windows installation is stored in C:\Windows.old for 10 days as a rollback option.
Edition-to-edition upgrades An in-place upgrade can also be used to upgrade editions (Home → Pro) within the same Windows version. In Windows 10/11, this is done via Settings → System → About → "Upgrade your edition of Windows" and entering a new product key. No media is needed for edition upgrades.
Supported in-place upgrade paths (version) Windows 10 → Windows 11 (in-place, using Windows Update or the Installation Assistant, if hardware meets requirements). Windows 7 or 8.1 → Windows 10 (via setup.exe from installation media). Direct in-place upgrades skipping versions (e.g., Windows 7 → Windows 11) are not officially supported.

The table below shows supported in-place upgrade edition paths within Windows. An upgrade is only valid from the same or a lower edition to a higher edition — you cannot downgrade editions via in-place upgrade.

Backup Before Any Upgrade

Despite the in-place upgrade's promise of preserving data, always back up user data before any upgrade. Upgrade failures — though uncommon — can leave the system in an unbootable state, and partial failures can cause data loss. The backup is insurance against the unexpected.

Clean Install

A clean install (also called a fresh install) wipes the target drive and installs Windows from scratch. No previous OS components, applications, or user data are carried over unless the technician explicitly migrates them. The result is the cleanest possible system — no leftover files, no registry cruft from previous applications, no compatibility baggage.

When to choose a clean install Deploying a new machine. Recovering from severe malware infection. Resolving persistent OS corruption that repair tools cannot fix. Changing editions in a way that in-place upgrade doesn't support (e.g., downgrading, or moving to a significantly different configuration). Decommissioning and redeploying hardware for a different user or department.
What is lost Everything on the target partition. All installed applications must be reinstalled. All user data must be restored from backup. All drivers must be reinstalled (Windows will attempt to install many automatically from Windows Update). All application settings are reset to defaults.
Installation media A clean install requires bootable installation media: typically a USB flash drive created with the Windows Media Creation Tool (available free from Microsoft), or a bootable ISO file mounted or burned to optical media. The system must be configured to boot from this external media (via BIOS/UEFI boot menu or boot order settings).
Product key / activation A clean install requires a valid product key. For systems with an OEM license (pre-installed Windows), the digital license is tied to the hardware's UEFI firmware — Windows 10 and 11 can activate automatically after a clean install on the same hardware without manually entering a key. For retail licenses, the key must be entered during or after installation.
Clean Install Procedure Overview
01
Back up all user data to an external drive, network share, or cloud storage. Verify the backup is complete and readable before proceeding.
02
Create bootable installation media. Download the Windows ISO from Microsoft and use the Media Creation Tool or Rufus to write it to a USB drive (8 GB minimum).
03
Boot from the installation media. Enter the BIOS/UEFI boot menu (typically F12, F2, DEL, or ESC at POST) and select the USB drive as the boot device, or adjust the boot order.
04
At the partition selection screen, delete existing partitions and create new ones. For a true clean install on the system drive, delete the old partition(s) and let the installer create fresh partitions, or select unallocated space.
05
Complete installation and initial setup (OOBE). Enter the product key when prompted (or skip for hardware-linked OEM licenses). Create a user account. Let Windows download updates.
06
Install drivers. Windows Update handles most drivers automatically, but GPU, chipset, and specialized peripheral drivers may need manual installation from manufacturer websites.
07
Reinstall applications and restore user data from the backup taken in step 1.

In-Place Upgrade vs. Clean Install: Exam Decision Point

On the exam, if a scenario says "keep all applications and files" → in-place upgrade. If the scenario says "malware-infected and unrecoverable" or "deploy fresh for a new user" → clean install. These are the two clearest use-case signals.

SECTION 7Hardware Requirements

Trusted Platform Module (TPM)

The Trusted Platform Module (TPM) is a dedicated security microcontroller — either a discrete physical chip on the motherboard or a firmware-based implementation in the processor — that performs cryptographic operations in hardware and provides a secure, isolated storage area for cryptographic keys, certificates, passwords, and measurements.

Physical vs. Firmware TPM A discrete TPM (dTPM) is a dedicated chip soldered onto the motherboard. A firmware TPM (fTPM) runs as software within the secure enclave of a modern processor (Intel PTT — Platform Trust Technology, or AMD fTPM). Both satisfy the TPM requirement and provide equivalent security for Windows purposes. Most modern CPUs include firmware TPM support.
TPM Versions TPM 1.2 and TPM 2.0 are the two versions. Windows 11 requires TPM 2.0. TPM 1.2 is insufficient. TPM 2.0 supports more modern cryptographic algorithms (SHA-256, ECC) and is more flexible in its key hierarchy. Windows 10 works with TPM 1.2 and 2.0.
What the TPM Does for Windows Stores the BitLocker encryption key — the TPM measures the boot configuration; if the hardware or early boot files change unexpectedly, the TPM refuses to release the key, protecting against offline attacks. Also used for Windows Hello biometric authentication credential storage, virtual smart card support, and attestation services (verifying the integrity of the system).
Enabling the TPM TPM is enabled in BIOS/UEFI settings. The option may be labeled "TPM," "PTT" (Intel), "fTPM" (AMD), or "Security Device." If a Windows 11 installation fails the hardware check and cites TPM as the issue, the first step is to verify the TPM is enabled in UEFI — it may be present but disabled. Check with the TPM Management console: run tpm.msc in Windows to see current TPM status.

Exam Focus — TPM and Windows 11

Windows 11 requires TPM 2.0. If a user cannot install or upgrade to Windows 11 and you see "this PC doesn't meet requirements," TPM 2.0 is the most likely culprit, especially on machines from 2015–2018. Check UEFI settings to see if the TPM is disabled (and enable it) before concluding the hardware is incompatible. TPM 1.2 does not satisfy the Windows 11 requirement — the user would need newer hardware.

Unified Extensible Firmware Interface (UEFI)

The Unified Extensible Firmware Interface (UEFI) is the modern replacement for the legacy BIOS (Basic Input/Output System) that initializes hardware and launches the operating system boot loader when a computer powers on. Understanding the differences between UEFI and BIOS is essential for both this objective (hardware requirements) and broader OS installation scenarios.

Legacy BIOS The original firmware standard, dating to the 1970s IBM PC. Uses a 16-bit real-mode interface, relies on the Master Boot Record (MBR) disk partition scheme, is limited to booting from drives up to 2.2 TB, and supports a maximum of 4 primary partitions. Text-based interface with keyboard-only navigation.
UEFI Modern firmware standard. 32-bit or 64-bit interface. Uses the GUID Partition Table (GPT) disk scheme, which supports drives larger than 2.2 TB and up to 128 primary partitions. GUI interface with mouse support. Faster boot times (no legacy BIOS initialization overhead). Platform for Secure Boot. Required by Windows 11.
Secure Boot A UEFI feature that cryptographically verifies the digital signatures of boot loaders and drivers before executing them. If the boot loader is not signed by a trusted key in the UEFI firmware's key database, Secure Boot refuses to execute it. This prevents boot sector malware and rootkits from loading before the OS. Windows 11 requires Secure Boot to be enabled. Windows 10 does not require it, but benefits from it.
UEFI Compatibility Support Module (CSM) The CSM is a UEFI feature that provides backward compatibility with legacy BIOS boot mechanisms, allowing older operating systems and bootable media to work. When CSM is enabled, the system can boot from MBR disks. Windows 11 requires Secure Boot, which is incompatible with CSM being enabled — installing Windows 11 typically requires disabling CSM and enabling Secure Boot in UEFI settings.
MBR vs. GPT Legacy BIOS boots from MBR (Master Boot Record) disks. UEFI boots from GPT (GUID Partition Table) disks. Windows 11 requires a GPT system disk when using UEFI mode. Attempting to install Windows 11 on an MBR-formatted disk in UEFI mode will fail. The disk can be converted (with data loss, using tools like diskpart or MBR2GPT) or reformatted.

UEFI Settings for Windows 11 Installation

Before installing Windows 11, verify three UEFI settings: (1) UEFI mode is enabled (CSM/legacy mode disabled), (2) Secure Boot is enabled, (3) TPM 2.0 is enabled. All three must be true for a successful Windows 11 installation. On many systems where the upgrade check fails, disabling CSM and enabling Secure Boot is the fix — the hardware actually meets the requirements but the firmware settings are wrong.

Scenario 5: Windows 11 upgrade check fails → Check for TPM 2.0, Secure Boot, and UEFI mode in BIOS settings.
Scenario 6: Windows Pro machine losing apps and files after upgrade → Should have used in-place upgrade, not clean install.
Scenario 7: N version machine has no sound in media player → Missing Media Feature Pack; not a hardware/driver issue.

Quick Identification Tips

To check which Windows edition is installed: press Win + Pause/Break → "About your PC" in Settings, or run winver in the Run dialog (Win + R). The edition is listed as "Windows 10 Home," "Windows 11 Pro," etc. You can also check via: Settings → System → About → Windows specifications. The "Edition" field is definitive.
