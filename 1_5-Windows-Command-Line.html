OVERVIEWIntroduction to the Windows Command Line

Behind every Windows graphical tool sits a command-line equivalent that's often faster, more scriptable, and more precise — invaluable when a GUI is unresponsive, when working over a limited remote connection, or when a task needs to run identically across many machines (tying directly into Objective 4.8's scripting concepts). Objective 1.5 covers the specific command-line utilities a technician is expected to know cold: what each one does, and — since command output is only useful if you can shape it — which switches matter most.

This objective organizes commands into six functional groups: navigation (moving around the filesystem), network (diagnosing connectivity), disk management (working with drives and partitions), file management (creating, removing, and copying files/folders), informational (querying system and user details), and OS management (applying policy and verifying system file integrity).

Core Concept — Commands Are Simple; Switches Do the Real Work

Nearly every command on this list is easy to run with no arguments at all — but the exam consistently tests specific switches, because that's where a command's real diagnostic or administrative power lives. ping alone tells you if a host answers; ping -t tells you if it answers consistently over time. Treat the base command as step one and the switches as the actual skill being tested.

SECTION 1Navigation Commands

These two commands are the most basic building blocks of working in a command-line environment — moving around the filesystem and seeing what's there.

cd Change Directory — moves between folders in the command-line session. cd .. moves up one level; cd \ jumps to the drive root; cd alone (no path) displays the current directory.
dir Directory — lists the files and folders in the current (or a specified) directory, including size, date modified, and whether an entry is a file or a subdirectory.

SECTION 2Network Commands

Network commands are the most heavily tested group on this objective, since network troubleshooting is such a common real-world technician task.

ipconfigIP Configuration
PurposeDisplays the current TCP/IP network configuration — IP address, subnet mask, default gateway — for all network adapters on the machine
Key switches/all shows full details including DNS servers and MAC address; /release and /renew drop and reacquire a DHCP-assigned address; /flushdns clears the local DNS resolver cache
pingPacket Internet Groper
PurposeSends ICMP echo request packets to a target host to test basic reachability and measure round-trip latency
Key switches-t pings continuously until stopped manually (useful for watching intermittent connectivity); -n [count] sets a specific number of pings; -a resolves the target's hostname
netstatNetwork Statistics
PurposeDisplays active network connections and listening ports on the local machine — useful for spotting unexpected open connections or a service listening on an unusual port
Key switches-a shows all connections and listening ports; -b shows the executable responsible for each connection; -n displays addresses/ports numerically instead of resolving names (faster output)
nslookupName Server Lookup
PurposeQueries DNS servers directly to resolve a hostname to an IP address (or vice versa), useful for diagnosing DNS-specific problems separate from general connectivity
Key switchesRun with no arguments to enter an interactive mode; nslookup [hostname] [DNS server] queries a specific DNS server directly rather than the system default
net useNetwork Use
PurposeConnects to, disconnects from, or lists shared network resources such as mapped drives and shared printers
Key switchesnet use Z: \\server\share maps a network drive to drive letter Z:; net use Z: /delete disconnects that mapping; net use alone lists all current connections
tracertTrace Route
PurposeMaps the path packets take to a destination host, listing every router hop along the way and the latency to each — useful for identifying exactly where along a route a connection is failing or slowing down
Key switches-d skips reverse DNS lookups for each hop, producing faster results; -h [max hops] limits how many hops the trace will attempt
pathpingPath Ping
PurposeCombines tracert and ping — traces the route to a destination and then sends repeated pings to each hop along the way, providing packet loss statistics per hop rather than just a single latency snapshot
Key switches-n skips resolving hostnames for faster output; -p [milliseconds] sets the wait time between pings to each hop

Exam Angle — tracert vs. pathping

tracert shows the route and a single latency reading per hop; pathping shows the route and sends sustained repeated pings to every hop, producing packet-loss percentages that reveal exactly which hop in a path is dropping traffic. If a scenario needs to identify which specific hop is unreliable over time — not just what the path looks like — pathping is the better tool.

SECTION 3Disk Management Commands

chkdskCheck Disk
PurposeScans a volume for filesystem errors and bad sectors, and can repair certain types of disk errors
Key switches/f fixes errors found on the disk; /r locates bad sectors and recovers readable information (implies /f); a scan requiring /f or /r on the active system volume typically requires a restart to run before Windows loads
formatFormat Volume
PurposeFormats a disk or partition with a specified filesystem, erasing existing data on that volume and preparing it for use
Key switches/fs:[filesystem] specifies the filesystem to use (e.g., /fs:ntfs); /q performs a quick format, skipping a full bad-sector scan
diskpartDisk Partition
PurposeLaunches an advanced, interactive disk-partitioning utility for creating, deleting, resizing, and managing partitions and volumes — more powerful than the graphical Disk Management console for scripted or advanced scenarios
Key usageOnce launched, uses its own internal commands (list disk, select disk [n], create partition primary, clean) rather than traditional command-line switches

Destructive Commands — Handle With Care

format and diskpart's clean command both destroy existing data on a volume. Always confirm the correct drive letter or disk number before running either — a mistyped target is one of the most common and costly command-line mistakes a technician can make.

SECTION 4File Management Commands

mdMake Directory
PurposeCreates a new directory (folder) at the specified path — e.g., md C:\Reports
rmdirRemove Directory
PurposeDeletes a directory — by default only if it's empty
Key switches/s removes a directory tree, including all files and subdirectories within it; /q suppresses the confirmation prompt when used with /s
robocopyRobust File Copy
PurposeA powerful, robust file/directory copy utility built for reliability over unstable connections and for mirroring large directory structures — far more capable than a simple copy command
Key switches/e copies all subdirectories, including empty ones; /mir mirrors a directory tree exactly, deleting files at the destination that no longer exist at the source; /z copies files in restartable mode, resuming an interrupted copy rather than starting over

Why robocopy Over a Basic copy Command

robocopy is specifically named on the exam (rather than the more basic copy or xcopy) because of its resilience — it can resume an interrupted transfer, mirror entire directory trees exactly, and preserve file attributes/permissions far more reliably, making it the preferred tool for scripted backups and large-scale file migrations.

SECTION 5Informational Commands

hostname Displays the computer's configured hostname — a quick way to confirm exactly which machine a command-line session is connected to.
net user Displays information about local user accounts, or creates/modifies them. net user alone lists all local accounts; net user [username] shows details for a specific account; net user [username] [password] can reset that account's password.
winver Opens a small dialog box displaying the exact Windows version and build number installed — useful for quickly confirming which edition/build a machine is running without digging through Settings.
whoami Displays the username of the account currently running the command-line session — useful for confirming exactly which account context a script or session is operating under, especially when troubleshooting permissions issues.
[command name] /? Appending /? to almost any Windows command-line tool displays its built-in help text — the full list of available switches and usage syntax — directly in the terminal, without needing to look it up externally.

SECTION 6OS Management Commands

gpupdateGroup Policy Update
PurposeForces an immediate refresh of Group Policy settings from the domain, rather than waiting for the next automatic background refresh cycle
Key switches/force reapplies all policy settings regardless of whether they've changed; /target:computer or /target:user refreshes only computer-based or only user-based policy
gpresultGroup Policy Result
PurposeDisplays the Group Policy settings that have actually been applied to a specific user or computer — useful for confirming whether an expected policy took effect and diagnosing policy conflicts
Key switches/r shows a summary of applied policy; /h [file.html] exports a detailed report to an HTML file for easier review
sfcSystem File Checker
PurposeScans protected system files for corruption and automatically repairs them using a cached copy, when possible — a first-line troubleshooting step for many Windows OS issues (Objective 3.1) like unexplained instability or missing system files
Key switches/scannow performs an immediate scan and repair of all protected system files; /verifyonly scans without making any repairs

Exam Angle — gpupdate vs. gpresult

gpupdate applies policy — it forces the refresh to happen now. gpresult reports policy — it shows what's already been applied, without changing anything. A scenario asking "how do I make a new policy take effect immediately" wants gpupdate; a scenario asking "how do I confirm which policies are actually in effect on this machine" wants gpresult.

REFERENCEQuick Reference Cards

Network Troubleshooting Order

  • 1. Check local config — ipconfig /all
  • 2. Test basic reachability — ping
  • 3. Check name resolution — nslookup
  • 4. Map the path/find the failure point — tracert or pathping

Disk/File Safety Reminders

  • format and diskpart clean — destroy data; verify target first
  • chkdsk /r on the system drive — usually requires a restart
  • robocopy /mir — deletes destination files not present at source

"Apply" vs. "Report" Command Pairs

  • gpupdate — applies Group Policy now
  • gpresult — reports what's already applied
  • sfc /scannow — repairs; sfc /verifyonly — reports only

Quick Identity/Info Checks

  • Which machine am I on? — hostname
  • Which account am I running as? — whoami
  • What Windows build is this? — winver
  • How do I use this command? — [command] /?

Final Exam Reminders

pathping combines tracert and ping — use it specifically when you need per-hop packet loss over time, not just a one-time route map.

chkdsk /r implies /f — recovering bad sectors always includes fixing filesystem errors, but not the reverse; know that /r is the more thorough of the two switches.

robocopy is specifically favored over basic copy/xcopy for its restartable transfers (/z) and exact mirroring (/mir) — expect scenario questions to hint at large, unreliable, or scheduled transfers as the signal to choose robocopy.

gpupdate changes state; gpresult only reports state — this apply-vs-report distinction is the same pattern as sfc /scannow (repairs) vs. sfc /verifyonly (reports only); recognizing this pattern helps generalize to unfamiliar command pairs too.

ipconfig /flushdns and nslookup both relate to DNS but serve different purposes — /flushdns clears the local cache (fixing stale local resolution), while nslookup queries a DNS server directly to test resolution at the source.

Appending /? works on nearly any command-line tool — a fast, always-available way to check exact syntax without leaving the terminal, and a valid answer whenever a scenario asks how to find a command's available options.
